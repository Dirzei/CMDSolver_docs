Theoretischer Kontext

Theoretical Context

BROYDEN_SPARSE kombiniert den Broyden Rang-1-Update mit GSPAR Sparse-LU — analog zu NEWTON_SPARSE_ARMIJO vs NEWTON_ARMIJO. Bei gut konditionierten Systemen kann dieser Solver 5–10× schneller sein als BROYDEN_DENSE.

BROYDEN_SPARSE combines the Broyden rank-1 update with GSPAR sparse LU — analogous to NEWTON_SPARSE_ARMIJO vs NEWTON_ARMIJO. On well-conditioned systems this solver can be 5–10× faster than BROYDEN_DENSE.

Schritt k (wenn kein Reset):Step k (no reset):
1. Rang-1-Update der Jacobi-Approximation J̃
1. Rank-1 update of the Jacobian approximation J̃
2. Sparse-LU: J̃ = L·U
3. Lösung: Δx via L·U·Δx = −F(x) (Substitution)
3. Solve: Δx via L·U·Δx = −F(x) (substitution)
Reset-Schritt (alle resetInterval Iterationen):Reset step (every resetInterval iterations):
Vollständiger Jacobi-Neuaufbau + neue GSPAR-Faktorisierung
Full Jacobian rebuild + new GSPAR factorization
Warum so schnell? Beim SimpleSystem-Test: Der Rang-1-Update ist günstiger als vollständiger Jacobi-Neuaufbau, GSPAR ist günstiger als dichte LU. Zusammen ergibt das ~9ms gegenüber ~42ms für NEWTON_ARMIJO. Bei größeren Systemen werden die Unterschiede noch ausgeprägter.
Why so fast? On the SimpleSystem test: the rank-1 update is cheaper than a full Jacobian rebuild, and GSPAR is cheaper than dense LU. Together that gives ~9 ms vs. ~42 ms for NEWTON_ARMIJO. On larger systems the gap widens further.

Pseudocode

Pseudocode

function broyden_sparse_solve(F, x₀, tol, maxIter, resetInterval):
    x ← InitGuessApplier(x₀)
    J ← buildJacobian(F, x)         // vollständiger Start// full start
    [L, U, P] ← gspar_lu(J)         // Sparse-LU Faktorisierung// sparse-LU factorization

    for k = 0 to maxIter:
        f ← F(x)
        Δx ← gspar_solve(L, U, P, −f)  // schnelle Substitution// fast substitution

        x_new ← x + Δx
        f_new ← F(x_new)

        // ── Broyden-Update oder Reset ──// ── Broyden update or reset ──
        if k % resetInterval == 0:
            J ← buildJacobian(F, x_new)
            [L, U, P] ← gspar_lu(J)
        else:
            Δf ← f_new − f
            J ← broyden_rank1_update(J, Δx, Δf)
            [L, U, P] ← gspar_lu(J)     // Re-Faktorisierung// re-factorization

        x ← x_new
        x ← PhysicalProjector(x)
        fsum ← Σ|Fᵢ(x)|
        if fsum < tol: return CONVERGED, x, k, fsum

    return NOT_CONVERGED, x, maxIter, fsum
