Solver Optionen
CLI Referenz

Vollständige Referenz aller Kommandozeilenargumente — allgemeine Optionen die für alle Solver gelten, und solver-spezifische Parameter.

Aufruf Allgemein Solver-Wahl Homotopie Broyden Diagnose Batch Übersicht

Grundaufruf

java CASSolver -I:<modelldatei> [optionen]
java CASSolver -I:model.cas -S:NEWTON_SPARSE_ARMIJO -DI
java CASSolver -I:model.cas -S:HOMOTOPY -SH:STEPS=50 -SH:DS=0.02 -SH:INNER=LEVENBERG_MARQUARDT
java CASSolver -I:model.csv -BA                          // Batch-Modus
java CASSolver -h                                        // Hilfe
java CASSolver -I:model.cas -TEST                        // alle Solver testen
Argumente sind case-insensitiv. -S:NEWTON_ARMIJO und -s:newton_armijo sind gleichwertig. Pfade folgen dem Betriebssystem (Windows: Backslash oder Forward-Slash).

Allgemeine Optionen — für alle Solver

-I:<datei>
Eingabedatei. Unterstützte Formate: .cas (Gleichungssystem), .dat (Gleichungssystem), .csv (Batch-Parameterstudie).
-I:model.cas    -I:C:\Work\nozzle.cas
Alle Solver
-S:<solver>
Solver-Auswahl. Standard: NEWTON_ARMIJO.
-S:NEWTON_SPARSE_ARMIJO    -S:LEVENBERG_MARQUARDT    -S:HOMOTOPY
NEWTON_ARMIJO NEWTON_SPARSE NEWTON_SPARSE_ARMIJO LEVENBERG_MARQUARDT BROYDEN BROYDEN_SPARSE HOMOTOPY
-U:<datei>
Variable-Update-Datei — überschreibt Startwerte, Bounds und Status aus der CAS-Datei. Format pro Zeile:
Name:VAR; Value:1.0; Status:Fixed; Lower:0.0; Upper:2.0; Unit:m/s; Descr:text
-U:betriebspunkt.txt
Alle Solver
-SC:<strategie>
Skalierungsstrategie für die Jacobi-Matrix. Standard: NONE.
NONE — keine Skalierung
DIAGONAL — Skalierung über Jacobi-Diagonale
UNIT_INTERVAL — Skalierung über Variablen-Bounds
-SC:DIAGONAL    -SC:UNIT_INTERVAL
Alle Solver
-SN
Residuen-Normierung (N3-Modus) aktivieren. Berechnet fsum als Σ|Fᵢ(x)|/|Fᵢ(x₀)| statt Σ|Fᵢ(x)|. Empfohlen bei Systemen mit sehr unterschiedlichen Gleichungsgrößenordnungen (z.B. Pa-Gleichungen neben kg/s-Gleichungen).
-SN
Alle Solver
-TEST
Test-Modus: alle 7 Solver werden nacheinander auf demselben Modell ausgeführt und verglichen. Startwerte werden für jeden Solver zurückgesetzt. Nützlich für Solver-Auswahl und Performance-Vergleich.
java CASSolver -I:model.cas -TEST
Alle Solver
-h / --help
Zeigt die vollständige Hilfe mit allen Argumenten und verfügbaren Solvern.
java CASSolver -h
Alle Solver

Allgemeine Solver-Parameter

Diese Parameter gelten für alle direkten Solver (Newton, LM, Broyden) — nicht für Homotopie (die hat eigene -SH: Parameter).

Hinweis: Toleranz und maximale Iterationen werden über SolverConfig gesetzt — aktuell nicht direkt über CLI-Argumente konfigurierbar. Standard-Werte: tol=1e-7, maxIter=100. Über SolverAPI sind diese Werte programmtisch setzbar.
ParameterDefaultGilt fürBeschreibung
tolerance1e-7 Alle direkten Solver Konvergenzschwelle: ||F(x)|| < tolerance
maxIter100 Alle direkten Solver Maximale Iterationen vor Abbruch
armijoAlphaInit1.0 NEWTON_ARMIJO, NEWTON_SPARSE_ARMIJO Initialer Schrittweiten-Faktor α
armijoAlphaMin1e-4 NEWTON_ARMIJO, NEWTON_SPARSE_ARMIJO Minimales α vor Abbruch der Liniensuche
armijoRho0.5 NEWTON_ARMIJO, NEWTON_SPARSE_ARMIJO Reduktionsfaktor pro Backtracking-Schritt
armijoC11e-4 NEWTON_ARMIJO, NEWTON_SPARSE_ARMIJO Wolfe-Bedingungskonstante c₁
lmMuInit1e-6 LEVENBERG_MARQUARDT Initialer μ-Faktor (× max Diagonale JᵀJ)
lmNuUp2.0 LEVENBERG_MARQUARDT μ-Erhöhungsfaktor bei schlechtem Schritt
lmNuDown5.0 LEVENBERG_MARQUARDT μ-Reduktionsfaktor bei gutem Schritt

Homotopie-Optionen -SH:...

Nur für -S:HOMOTOPY — alle -SH: Argumente werden ignoriert wenn ein anderer Solver gewählt ist.
-SH:STEPS=<n>
Anzahl der Homotopie-Schritte (Pfadpunkte). Standard: 10. Mehr Schritte = kleinere Einzelschritte = robuster aber langsamer. Bei komplexen Systemen: 50–100.
-SH:STEPS=50
Nur HOMOTOPY
-SH:DS=<x>
Initiale Schrittweite Δt entlang des Homotopie-Pfades. Standard: 0.1. Bei numerisch schwierigen Systemen (nahe Ma=1, Phasenübergang): 0.02.
-SH:DS=0.02    -SH:DS=0.05
Nur HOMOTOPY
-SH:INNER=<solver>
Innerer Korrektor-Solver für jeden Homotopie-Schritt. Standard: NEWTON_ARMIJO. Bei schlecht konditionierten Systemen (κ > 10¹²): LEVENBERG_MARQUARDT.
-SH:INNER=LEVENBERG_MARQUARDT    -SH:INNER=NEWTON_SPARSE_ARMIJO
Nur HOMOTOPY
-SH:CRITICAL
Vorkonfigurierte Einstellung für kritische Systeme (z.B. Strömung nahe Ma=1, Phasenübergänge). Setzt automatisch: STEPS=50, DS=0.02, DSMAX=0.1, ITER_TARGET=3.
-SH:CRITICAL
Nur HOMOTOPY

Vollständiges Beispiel

java CASSolver -I:nozzle.cas \
  -S:HOMOTOPY \
  -SH:INNER=LEVENBERG_MARQUARDT \
  -SH:STEPS=50 \
  -SH:DS=0.02

Broyden-Optionen -SB:...

Nur für -S:BROYDEN und -S:BROYDEN_SPARSE
-SB:RESET=<n>
Jacobi-Reset-Intervall — alle n Iterationen wird die Jacobi vollständig neu berechnet statt durch Rang-1-Update aktualisiert. Standard: 25. Kleinere Werte: robuster aber langsamer. Größere Werte: schneller aber mehr Akkumulationsfehler.
-SB:RESET=10    -SB:RESET=50
Nur BROYDEN / BROYDEN_SPARSE
-SB:KAPPA=<x>
Konditionszahl-Schwellwert für erzwungenen Reset. Standard: 1e10. Wenn κ(J) diesen Wert überschreitet, wird die Jacobi sofort neu aufgebaut unabhängig vom Reset-Intervall.
-SB:KAPPA=1e8
Nur BROYDEN / BROYDEN_SPARSE
-SB:WARMKAPPA=<x>
Konditionszahl-Schwellwert für Warm-Start bei Parameterstudien. Wenn der Startvektor vom vorherigen BatchRunner-Run übernommen wird, wird die Jacobi nur neu aufgebaut wenn κ diesen Wert überschreitet.
-SB:WARMKAPPA=1e6
Nur BROYDEN / BROYDEN_SPARSE

Diagnose- und Debug-Optionen

-DI
Diagnose-Modus: Führt vor dem eigentlichen Solve einen InitialValueAnalyzer-Durchlauf durch. Optimiert Startwerte automatisch — besonders nützlich wenn viele Variablen schlecht initialisiert sind. Der Solver startet dann mit einem besseren Startvektor.
java CASSolver -I:model.cas -DI
Alle Solver
-DV:<datei>
Startvektor-Dump: Schreibt alle Variablenwerte vor Iteration 0 in eine Textdatei im -U:-Format. Nützlich für Debugging — der Dump kann direkt als -U:-Datei wiederverwendet werden.
-DV:startvektor.txt
Nur NEWTON_ARMIJO

Batch-Optionen

-I:<datei.csv>
Batch-Modus: Wenn die Eingabedatei eine .csv-Datei ist, wird automatisch BatchRunner aktiviert. Die CSV enthält eine Zeile pro Betriebspunkt mit Variablenwerten. Die zugehörige .cas-Datei wird automatisch gesucht (gleiches Verzeichnis, gleicher Name).
java CASSolver -I:parameterstudie.csv
Alle Solver
-BA
Batch-Ausgabe: Alle Variablen in die Batch-Ausgabedatei schreiben — auch fixierte Variablen. Standard: nur freie Variablen.
java CASSolver -I:studie.csv -BA
Alle Solver (nur Batch)

Schnellreferenz — häufigste Kombinationen

// Standard (empfohlen für die meisten Systeme)
java CASSolver -I:model.cas

// Mit schlechten Startwerten
java CASSolver -I:model.cas -DI

// Großes System, guter Startvektor
java CASSolver -I:model.cas -S:NEWTON_SPARSE_ARMIJO

// Schlecht konditioniert (κ-Warnungen im Log)
java CASSolver -I:model.cas -S:LEVENBERG_MARQUARDT

// Newton scheitert, LM scheitert
java CASSolver -I:model.cas -S:HOMOTOPY -SH:INNER=LEVENBERG_MARQUARDT -SH:STEPS=50 -SH:DS=0.02

// Parameterstudie
java CASSolver -I:studie.csv -S:BROYDEN_SPARSE

// Solver vergleichen
java CASSolver -I:model.cas -TEST

// Startvektor analysieren
java CASSolver -I:model.cas -DV:start.txt -S:NEWTON_ARMIJO
