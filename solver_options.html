Grundaufruf

Basic Invocation

java CASSolver -I:<modelldatei> [optionen]
java CASSolver -I:model.cas -S:NEWTON_SPARSE_ARMIJO -DI
java CASSolver -I:model.cas -S:HOMOTOPY -SH:STEPS=50 -SH:DS=0.02 -SH:INNER=LEVENBERG_MARQUARDT
java CASSolver -I:model.csv -BA                          // Batch-Modus// batch mode
java CASSolver -h                                        // Hilfe// help
java CASSolver -I:model.cas -TEST                        // alle Solver testen// test all solvers
Argumente sind case-insensitiv. -S:NEWTON_ARMIJO und -s:newton_armijo sind gleichwertig. Pfade folgen dem Betriebssystem (Windows: Backslash oder Forward-Slash).
Arguments are case-insensitive. -S:NEWTON_ARMIJO and -s:newton_armijo are equivalent. Paths follow the operating system (Windows: backslash or forward slash).

Homotopie-Optionen -SH:...

Homotopy Options -SH:...

Nur für -S:HOMOTOPY — alle -SH: Argumente werden ignoriert wenn ein anderer Solver gewählt ist.
Only for -S:HOMOTOPY — all -SH: arguments are ignored when a different solver is selected.
-SH:STEPS=<n>
Anzahl der Homotopie-Schritte (Pfadpunkte). Standard: 10. Mehr Schritte = kleinere Einzelschritte = robuster aber langsamer. Bei komplexen Systemen: 50–100.
Number of homotopy steps (path points). Default: 10. More steps = smaller individual steps = more robust but slower. For complex systems: 50–100.
-SH:STEPS=50
Nur HOMOTOPYHOMOTOPY only
-SH:DS=<x>
Initiale Schrittweite Δt entlang des Homotopie-Pfades. Standard: 0.1. Bei numerisch schwierigen Systemen (nahe Ma=1, Phasenübergang): 0.02.
Initial step size Δt along the homotopy path. Default: 0.1. For numerically difficult systems (near Ma=1, phase transition): 0.02.
-SH:DS=0.02    -SH:DS=0.05
Nur HOMOTOPYHOMOTOPY only
-SH:INNER=<solver>
Innerer Korrektor-Solver für jeden Homotopie-Schritt. Standard: NEWTON_ARMIJO. Bei schlecht konditionierten Systemen (κ > 10¹²): LEVENBERG_MARQUARDT.
Inner corrector solver for each homotopy step. Default: NEWTON_ARMIJO. On ill-conditioned systems (κ > 10¹²): LEVENBERG_MARQUARDT.
-SH:INNER=LEVENBERG_MARQUARDT    -SH:INNER=NEWTON_SPARSE_ARMIJO
Nur HOMOTOPYHOMOTOPY only
-SH:CRITICAL
Vorkonfigurierte Einstellung für kritische Systeme (z.B. Strömung nahe Ma=1, Phasenübergänge). Setzt automatisch: STEPS=50, DS=0.02, DSMAX=0.1, ITER_TARGET=3.
Preset for critical systems (e.g., flow near Ma=1, phase transitions). Automatically sets: STEPS=50, DS=0.02, DSMAX=0.1, ITER_TARGET=3.
-SH:CRITICAL
Nur HOMOTOPYHOMOTOPY only

Broyden-Optionen -SB:...

Broyden Options -SB:...

Nur für -S:BROYDEN und -S:BROYDEN_SPARSE
Only for -S:BROYDEN and -S:BROYDEN_SPARSE
-SB:RESET=<n>
Jacobi-Reset-Intervall — alle n Iterationen wird die Jacobi vollständig neu berechnet statt durch Rang-1-Update aktualisiert. Standard: 25. Kleinere Werte: robuster aber langsamer. Größere Werte: schneller aber mehr Akkumulationsfehler.
Jacobian reset interval — every n iterations the Jacobian is fully rebuilt instead of being updated via rank-1 update. Default: 25. Smaller values: more robust but slower. Larger values: faster but more accumulated error.
-SB:RESET=10    -SB:RESET=50
Nur BROYDEN / BROYDEN_SPARSEBROYDEN / BROYDEN_SPARSE only
-SB:KAPPA=<x>
Konditionszahl-Schwellwert für erzwungenen Reset. Standard: 1e10. Wenn κ(J) diesen Wert überschreitet, wird die Jacobi sofort neu aufgebaut unabhängig vom Reset-Intervall.
Condition-number threshold for forced reset. Default: 1e10. When κ(J) exceeds this value, the Jacobian is rebuilt immediately regardless of the reset interval.
-SB:KAPPA=1e8
Nur BROYDEN / BROYDEN_SPARSEBROYDEN / BROYDEN_SPARSE only
-SB:WARMKAPPA=<x>
Konditionszahl-Schwellwert für Warm-Start bei Parameterstudien. Wenn der Startvektor vom vorherigen BatchRunner-Run übernommen wird, wird die Jacobi nur neu aufgebaut wenn κ diesen Wert überschreitet.
Condition-number threshold for warm-start in parameter studies. When the starting vector is carried over from the previous BatchRunner run, the Jacobian is rebuilt only when κ exceeds this value.
-SB:WARMKAPPA=1e6
Nur BROYDEN / BROYDEN_SPARSEBROYDEN / BROYDEN_SPARSE only

Diagnose- und Debug-Optionen

Diagnostic and Debug Options

-DI
Diagnose-Modus: Führt vor dem eigentlichen Solve einen InitialValueAnalyzer-Durchlauf durch. Optimiert Startwerte automatisch — besonders nützlich wenn viele Variablen schlecht initialisiert sind. Der Solver startet dann mit einem besseren Startvektor.
Diagnostic mode: runs an InitialValueAnalyzer pass before the actual solve. Optimizes starting values automatically — especially useful when many variables are poorly initialized. The solver then starts with a better starting vector.
java CASSolver -I:model.cas -DI
Alle SolverAll solvers
-DIAG
Pre-Solve Modell-Diagnose: Analysiert das Gleichungssystem vor dem Solve systematisch und erstellt einen HTML-Bericht (model_diagnostics.html neben der CAS-Datei) mit Traffic-Light Status (GREEN/AMBER/RED).

Analysierte Kategorien:
  • Bounds Consistency — Lower > Upper, Value außerhalb Bounds, zu enge/weite Bounds, negative Bounds für physikalische Einheiten
  • NaN Risk — SQRT/LOG/LN mit problematischen Bounds (bounds-basiert, keine False Positives bei sicheren Bounds)
  • Scale Analysis — Größenordnungs-Spanne über alle Variablen, Warnung ab 10⁴, Fehler ab 10⁸
  • Structural Analysis — Orphaned Variables, Constant Equations, System-Balance (freie Variablen vs. Gleichungen)
  • Jacobian Analysis — κ bei x₀, Null-Zeilen (nur bei freien Variablen mit Ableitungen ≈ 0), Null-Spalten
  • Residual Analysis — NaN in F(x₀), Residuen-Dominanz
Bei NOT_CONVERGED wird der Bericht automatisch erzeugt (auch ohne -DIAG).
Am Ende des Reports: konkrete Solver-Empfehlung basierend auf den Befunden.
Pre-solve model diagnostics: systematically analyzes the equation system before the solve and produces an HTML report (model_diagnostics.html next to the CAS file) with traffic-light status (GREEN/AMBER/RED).

Categories analyzed:
  • Bounds consistency — Lower > Upper, value outside bounds, bounds too tight/wide, negative bounds for physical units
  • NaN risk — SQRT/LOG/LN with problematic bounds (bounds-based, no false positives on safe bounds)
  • Scale analysis — magnitude span across all variables, warning from 10⁴, error from 10⁸
  • Structural analysis — orphaned variables, constant equations, system balance (free variables vs. equations)
  • Jacobian analysis — κ at x₀, zero rows (only on free variables with derivatives ≈ 0), zero columns
  • Residual analysis — NaN in F(x₀), residual dominance
On NOT_CONVERGED the report is generated automatically (even without -DIAG).
End of the report: concrete solver recommendation based on the findings.
java CASSolver -I:model.cas -DIAG -S:NEWTON_SPARSE_ARMIJO -SC:EQUILIBRATE

Batch-Optionen

Batch Options

-I:<datei.csv>
Batch-Modus: Wenn die Eingabedatei eine .csv-Datei ist, wird automatisch BatchRunner aktiviert. Die CSV enthält eine Zeile pro Betriebspunkt mit Variablenwerten. Die zugehörige .cas-Datei wird automatisch gesucht (gleiches Verzeichnis, gleicher Name). → Vollständige Batch-Dokumentation
Batch mode: when the input file is a .csv, BatchRunner is activated automatically. The CSV contains one line per operating point with variable values. The matching .cas file is located automatically (same directory, same name). → Full batch documentation
java CASSolver -I:parameterstudie.csv
Alle Solver
-BA
Batch-Ausgabe: Alle Variablen in die Batch-Ausgabedatei schreiben — auch fixierte Variablen. Standard: nur freie Variablen.
Batch output: write all variables to the batch output file — including fixed variables. Default: only free variables.
java CASSolver -I:studie.csv -BA
Alle Solver (nur Batch)All solvers (batch only)
-BC:JUMPTHRESH=<wert>
Warm-Start Sprung-Erkennung: Wenn sich ein Input-Wert zwischen zwei aufeinanderfolgenden Runs um mehr als den angegebenen relativen Anteil ändert, wird der Warm-Start verworfen und mit den CAS-Startwerten neu begonnen.

Standard: 0.20 (20%). Der maximale relative Sprung wird über alle Input-Spalten berechnet:
relJump = |neu - alt| / max(|alt|, |neu|, 1e-10)

Besonders nützlich bei Sägezahnkurven als Batch-Input — verhindert dass der Warm-Start bei großen Sprüngen den Solver fehlleitet. 0 deaktiviert die Erkennung vollständig.
Warm-start jump detection: if an input value changes between two consecutive runs by more than the given relative fraction, the warm start is discarded and the run restarts with the CAS starting values.

Default: 0.20 (20 %). The maximum relative jump is computed across all input columns:
relJump = |new - old| / max(|old|, |new|, 1e-10)

Particularly useful with sawtooth curves as batch input — prevents the warm start from misleading the solver on large jumps. 0 disables detection entirely.
java CASSolver -I:studie.csv -BC:JUMPTHRESH=0.10
Alle Solver (nur Batch)All solvers (batch only)

Schnellreferenz — häufigste Kombinationen

Quick reference — most common combinations

// Standard (empfohlen für die meisten Systeme)// Default (recommended for most systems)
java CASSolver -I:model.cas

// Mit schlechten Startwerten// With poor starting values
java CASSolver -I:model.cas -DI

// Großes System, guter Startvektor// Large system, good starting vector
java CASSolver -I:model.cas -S:NEWTON_SPARSE_ARMIJO

// Schlecht konditioniert (κ-Warnungen im Log)// Ill-conditioned (κ warnings in the log)
java CASSolver -I:model.cas -S:LEVENBERG_MARQUARDT

// Newton scheitert, LM scheitert// Newton fails, LM fails
java CASSolver -I:model.cas -S:HOMOTOPY -SH:INNER=LEVENBERG_MARQUARDT -SH:STEPS=50 -SH:DS=0.02

// Parameterstudie// Parameter study
java CASSolver -I:studie.csv -S:BROYDEN_SPARSE

// Solver vergleichen// Compare solvers
java CASSolver -I:model.cas -TEST

// Startvektor analysieren// Analyze starting vector
java CASSolver -I:model.cas -DV:start.txt -S:NEWTON_ARMIJO
