Warum dieser Solver als Standard empfohlen wird: Er vereint quadratische Konvergenz (Newton), Geschwindigkeit (Sparse-LU) und Robustheit (Armijo). Für die meisten thermodynamischen Systeme in CMDSolver ist dies die optimale Wahl.
Why this solver is recommended as default: it unites quadratic convergence (Newton), speed (sparse LU) and robustness (Armijo). For most thermodynamic systems in CMDSolver this is the optimal choice.

Pseudocode

Pseudocode

function newton_sparse_armijo_solve(F, x₀, tol, maxIter):
    x ← InitGuessApplier(x₀)
    f0sq_init ← ||F(x₀)||²    // für relative Konvergenz// for relative convergence

    for k = 0 to maxIter:
        J ← buildJacobian(F, x)        // parallel// parallel
        f ← F(x)

        // ── GSPAR Sparse-LU ──// ── GSPAR sparse LU ──
        Δx ← gspar_solve(J, −f)        // kein J⁻¹// no J⁻¹

        // ── Armijo-Backtracking ──// ── Armijo backtracking ──
        α ← 1.0
        f0sq ← ||f||²
        while α > α_min:
            x_try ← x + α · Δx
            if ||F(x_try)||² ≤ f0sq + c₁·α·(−f0sq):
                break
            α ← α · 0.5

        x ← x + α · Δx
        x ← PhysicalProjector(x)

        fsum ← Σ|Fᵢ(x)|
        if fsum < tol: return CONVERGED, x, k, fsum

    return NOT_CONVERGED, x, maxIter, fsum
