Theoretischer Kontext

NEWTON_SPARSE_ARMIJO kombiniert die Stärken von NEWTON_SPARSE und NEWTON_ARMIJO:

KomponenteVonVorteil
GSPAR Sparse-LU NEWTON_SPARSE O(nnz) statt O(n³) — bis zu 10× schneller bei großen Systemen
Armijo-Liniensuche NEWTON_ARMIJO Schrittweitendämpfung — vergrößerter Einzugsbereich
Schritt k:
Δxₖ ← gspar_solve(J, −F(x)) ← Sparse-LU, kein J⁻¹
α ← armijo_search(x, Δx, F) ← Backtracking
xₖ₊₁ = xₖ + α · Δxₖ
Vorteil gegenüber NEWTON_ARMIJO:
Kein J⁻¹ berechnen — direkte LU-Lösung ist stabiler und schneller
Warum dieser Solver als Standard empfohlen wird: Er vereint quadratische Konvergenz (Newton), Geschwindigkeit (Sparse-LU) und Robustheit (Armijo). Für die meisten thermodynamischen Systeme in CMDSolver ist dies die optimale Wahl.

Pseudocode

function newton_sparse_armijo_solve(F, x₀, tol, maxIter):
    x ← InitGuessApplier(x₀)
    f0sq_init ← ||F(x₀)||²    // für relative Konvergenz

    for k = 0 to maxIter:
        J ← buildJacobian(F, x)        // parallel
        f ← F(x)

        // ── GSPAR Sparse-LU ──
        Δx ← gspar_solve(J, −f)        // kein J⁻¹

        // ── Armijo-Backtracking ──
        α ← 1.0
        f0sq ← ||f||²
        while α > α_min:
            x_try ← x + α · Δx
            if ||F(x_try)||² ≤ f0sq + c₁·α·(−f0sq):
                break
            α ← α · 0.5

        x ← x + α · Δx
        x ← PhysicalProjector(x)

        fsum ← Σ|Fᵢ(x)|
        if fsum < tol: return CONVERGED, x, k, fsum

    return NOT_CONVERGED, x, maxIter, fsum
