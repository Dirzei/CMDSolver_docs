Was wird modelliert?

What is modeled?

Ein vereinfachtes thermodynamisches System mit algebraischen Abhängigkeiten zwischen Druck, Temperatur, Massenstrom und abgeleiteten Größen. Das Modell ist speziell für Tests konzipiert — realistisch konditioniert aber ohne physikalisch kritische Bereiche (kein Ma-Übergang, keine Phasenübergänge).

A simplified thermodynamic system with algebraic dependencies between pressure, temperature, mass flow, and derived quantities. The model is specifically designed for testing — realistically conditioned but without physically critical regions (no Mach transition, no phase transitions).

Was wird modelliert?

Ein vollständiges aerothermodynamisches Modell einer Schubdüse (Nozzle) mit Mischer und Jetpipe. Das Modell berechnet Strömungsgrößen in mehreren Stationen (F060, F080, F090, ...) vom Kerngasstrom über den Bypass bis zum Düsenaustritt. Kerngrößen: Totaldruck, Totaltemperatur, Massenstrom, statischer Druck, Machzahl, spezifische Wärme, Isentropenexponent.

A complete aerothermodynamic model of a thrust nozzle with mixer and jet pipe. The model computes flow quantities at several stations (F060, F080, F090, …) from the core flow through the bypass to the nozzle exit. Key quantities: total pressure, total temperature, mass flow, static pressure, Mach number, specific heat, isentropic exponent.

Solver-Empfehlung für dieses Modell

Solver recommendation for this model

// Empfohlen: Newton-Sparse-Armijo mit Diagnose-Modus// Recommended: Newton-Sparse-Armijo with diagnostic mode
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:NEWTON_SPARSE_ARMIJO \
    -DI

// Falls Newton nicht konvergiert: Levenberg-Marquardt// If Newton does not converge: Levenberg-Marquardt
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:LEVENBERG_MARQUARDT \
    -DI

// Bei κ-Warnungen und LM-Problemen: Homotopie kritisch// On κ warnings and LM issues: homotopy critical
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:HOMOTOPY \
    -SH:CRITICAL \
    -SH:INNER=LEVENBERG_MARQUARDT
Bekanntes Problem: Das NozzleSystem_4_fixed konvergiert mit Newton und LM bei guten Startwerten. Homotopie zeigt bei diesem Modell Stagnationsverhalten — Verbesserung durch echten Tangenten-Prädiktor geplant (Roadmap R-03). Bei Konvergenzproblemen zuerst -DI versuchen und Startwerte in der -U:-Datei manuell setzen.
Known issue: NozzleSystem_4_fixed converges with Newton and LM given good starting values. Homotopy shows stagnation on this model — improvement via a true tangent predictor is planned (Roadmap R-03). On convergence issues, try -DI first and set starting values manually in the -U: file.
