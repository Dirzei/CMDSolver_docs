Was wird modelliert?

Ein vereinfachtes thermodynamisches System mit algebraischen Abhängigkeiten zwischen Druck, Temperatur, Massenstrom und abgeleiteten Größen. Das Modell ist speziell für Tests konzipiert — realistisch konditioniert aber ohne physikalisch kritische Bereiche (kein Ma-Übergang, keine Phasenübergänge).

Interessante Gleichungstypen

Gleichgewichtsgleichung — direkte Zuweisung
PARTM.F060.GAMMAT = PARTM.F060.CPT / (PARTM.F060.CPT - PARTM.F060.RGAS); // Isentropenexponent κ = cp / (cp - R)
CALL-Gleichung — thermodynamische Built-in Funktion
CALL(PARTM.F060.CPT) = pCPOFT(PARTM.F060.TT, PARTM.F060.WGR, PARTM.F060.FAR); // cp(T, WGR, FAR) aus BIfunctions.CpOfTNOZ() // Ableitung numerisch (5-Punkte-Formel)
Nichtlineare Gleichung — Potenz
PARTM.F060.PS = PARTM.F060.PT * (1 - EXP1 * PARTM.F060.GAMMAT)^EXP2; // Statischer Druck aus Totaldruck via isentrope Beziehung // EXP1, EXP2 = fixierte Hilfsgrößen aus dem INITIALIZE-Block

java -cp "CMDSolver.jar;libs/CASprzak.jar" cmd.CASSolver \

SolverAPI-Aufruf

    System.out.printf("%-35s = %.6g%n", k, v));
Als Regressions-Baseline: SimpleSystem.cas ist das Referenzsystem für alle Solver-Tests. Nach jeder Änderung am Code muss -TEST auf diesem Modell alle 7 Solver mit identischen Residuen liefern. Referenzwerte: Newton 3 Iter / 3.16e-11, BroydenSparse ~9ms.

Was wird modelliert?

Ein vollständiges aerothermodynamisches Modell einer Schubdüse (Nozzle) mit Mischer und Jetpipe. Das Modell berechnet Strömungsgrößen in mehreren Stationen (F060, F080, F090, ...) vom Kerngasstrom über den Bypass bis zum Düsenaustritt. Kerngrößen: Totaldruck, Totaltemperatur, Massenstrom, statischer Druck, Machzahl, spezifische Wärme, Isentropenexponent.

Modellstruktur

BereichVariablen-PrefixInhalt
GlobalGLOBAL.*Konstanten (π, R_univ, Schalter)
GeometrieGEOM.*Radien, Längen, Flächen
AtmosphäreAMB.*ISA-Bedingungen, Gaszusammensetzung
KerngasstromPARTM.F060.*Station 060: Eintritt Kerngasstrom
BypassPARTM.F080.*Station 080: Bypass-Strom
MischerPARTM.F090.*Station 090: nach Mischung
DüsenaustrittPARTM.F100.*Station 100: Düsenaustritt
GesamtmodellFULLM.*Schub, Schallgeschwindigkeit, Durchfluss

Interessante Gleichungstypen

Struktureller IF — Betriebsmodus-Schalter
IF (GLOBAL.STATICSWITCH.SPEC == FIXED) PARTM.F080.PS = AMB.PS; ELSE PARTM.F080.PS = PARTM.F060.PS * GLOBAL.STATICSWITCH; ENDIF // Schaltet zwischen Betriebsmodi zur Parse-Zeit — nicht zur Laufzeit // STATICSWITCH.Spec == Fixed → Umgebungsdruck direkt vorgegeben
MofCondiRatio — Machzahl aus Flächenverhältnis
CALL(FULLM.HTMAX.MA) = pMOFCONDIRATIO(FULLM.HTMAX.ARAT, FULLM.HTMAX.GAMMAT); // Löst A/A* = f(Ma, κ) numerisch nach Ma auf // Transzendente Gleichung — nur numerisch lösbar // Ableitung via 5-Punkte-Formel in BIfunctions
JANAF-Enthalpieberechnung
CALL(PARTM.F060.HT) = pHTOFTJANAF(PARTM.F060.TT, AMB.FN2, AMB.FO2, AMB.FAR, AMB.FCO2, AMB.FNE, AMB.FHE, AMB.FCH4, AMB.FKR, AMB.FH2, AMB.FN2O, AMB.FXE, AMB.FH2O); // Spezifische Enthalpie h(T) für Gasgemisch via JANAF-Polynome // 13 Eingaben — vollständige Gaszusammensetzung

Warum ist dieses Modell schwierig?

UrsacheAuswirkung
Konditionszahl κ ~ 10²³ Druck in Pa (10⁵) und dimensionslose Größen (10⁻³) nebeneinander — riesige Spanne
JANAF-Polynome als Built-in Funktionen Numerische Ableitungen statt symbolischer — leicht mehr Fehler in der Jacobi
MofCondiRatio nahe Ma=1 Funktion hat vertikale Tangente bei Ma=1 — Jacobi-Singularität möglich
Starke Kopplung aller Stationen Jede Gleichung hängt von vielen anderen ab — dichte Jacobi trotz Sparse-Struktur

Solver-Empfehlung für dieses Modell

// Empfohlen: Newton-Sparse-Armijo mit Diagnose-Modus
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:NEWTON_SPARSE_ARMIJO \
    -DI

// Falls Newton nicht konvergiert: Levenberg-Marquardt
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:LEVENBERG_MARQUARDT \
    -DI

// Bei κ-Warnungen und LM-Problemen: Homotopie kritisch
java cmd.CASSolver \
    -I:example/NozzleSystem_4_fixed.cas \
    -S:HOMOTOPY \
    -SH:CRITICAL \
    -SH:INNER=LEVENBERG_MARQUARDT
Bekanntes Problem: Das NozzleSystem_4_fixed konvergiert mit Newton und LM bei guten Startwerten. Homotopie zeigt bei diesem Modell Stagnationsverhalten — Verbesserung durch echten Tangenten-Prädiktor geplant (Roadmap R-03). Bei Konvergenzproblemen zuerst -DI versuchen und Startwerte in der -U:-Datei manuell setzen.

Eigenes Modell aufbauen — Schritt für Schritt

Empfohlene Vorgehensweise beim Aufbau eines neuen CAS-Modells:

SchrittAktionTipp
1 Variablen definieren — erst alle Fixed, dann Free Beginne mit physikalisch bekannten Größen als Fixed. Nur was wirklich unbekannt ist als Free.
2 Gleichgewicht prüfen: n Gleichungen = n Freie -I:model.cas -TEST zeigt Systemgröße. Zu viele Gleichungen → System überbestimmt.
3 Startwerte physikalisch sinnvoll wählen Schlechte Startwerte sind häufigste Konvergenz-Ursache. Mit -DI automatisch verbessern.
4 Bounds setzen Lower/Upper sollten physikalisch sinnvoll sein — PhysicalProjector verhindert negative Drücke etc.
5 Mit Newton-Sparse-Armijo testen Konvergiert meist in 3–10 Iterationen bei gut formulierten Systemen.
6 Falls nicht konvergiert: Diagnose Log nach κ-Warnungen durchsuchen. -DV:start.txt Startvektor inspizieren.
7 Batch-Parameterstudie CSV-Datei mit Betriebspunkten → -I:studie.csv. BroydenSparse für schnelle Serien.

Minimales Starter-Template

// template.cas — Minimal-Vorlage für ein neues Modell

// ── Fixierte Eingangsgrößen ────────────────────────────
IN_A AS REAL (Description: "Eingangsgröße A", Lower: 0, Value: 100, Upper: 1000, Spec: Fixed, Unit: "Pa");
IN_B AS REAL (Description: "Eingangsgröße B", Lower: 0, Value: 300, Upper: 600, Spec: Fixed, Unit: "K");

// ── Unbekannte (freie Variablen) ───────────────────────
OUT_X AS REAL (Description: "Unbekannte X", Lower: 0, Value: 50, Upper: 500, Spec: Free, Unit: "Pa");
OUT_Y AS REAL (Description: "Unbekannte Y", Lower: 200, Value: 290, Upper: 400, Spec: Free, Unit: "K");

// ── Gleichungen (n frei = n Gleichungen) ───────────────
OUT_X = IN_A * 0.5;                      // Gleichung 1
OUT_Y = IN_B - 10;                        // Gleichung 2

// Aufruf:
// java cmd.CASSolver -I:template.cas -S:NEWTON_SPARSE_ARMIJO
