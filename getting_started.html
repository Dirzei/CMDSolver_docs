Getting Started

Von Null zum ersten Ergebnis in 10 Minuten — CLI-Aufruf, SolverAPI-Einbettung und Ergebnis auslesen. Zwei Einstiegspfade je nach Anwendungsfall.

Voraussetzungen CLI-Einstieg API-Einstieg Ergebnis lesen Nächste Schritte

Voraussetzungen

KomponenteVersionBeschaffung
Java JDK11+ GraalVM 25 oder OpenJDK 17/21 empfohlen
CASprzak.jar0.3.0 Im Repository unter libs/CASprzak.jar

java -cp "CMDSolver.jar;libs/CASprzak.jar" cmd.CASSolver -I:model.cas

In Eclipse: Properties → Java Build Path → Libraries → CASprzak.jar hinzufügen.

Einstiegspfad 1 — CLI (Command Line)

Wähle diesen Pfad wenn: Du CMDSolver direkt von der Kommandozeile oder aus einem Skript aufrufen willst — ohne Java-Code zu schreiben.
1
CAS-Modell bereitstellen

Lege eine .cas-Datei mit Variablen und Gleichungen an. Das einfachste Beispiel — ein lineares System mit 2 Unbekannten:

// simple.cas — 2 Gleichungen, 2 Unbekannte
X AS REAL (Description: "Unbekannte X", Lower: -100, Value: 1, Upper: 100, Spec: Free, Unit: "-");
Y AS REAL (Description: "Unbekannte Y", Lower: -100, Value: 1, Upper: 100, Spec: Free, Unit: "-");

// Gleichung 1: X + Y = 10
X + Y = 10;

// Gleichung 2: X - Y = 4  →  Lösung: X=7, Y=3
X - Y = 4;
2
Solver aufrufen
java -cp "CMDSolver.jar;libs/CASprzak.jar" cmd.CASSolver -I:simple.cas

Mit expliziter Solver-Wahl und Diagnose-Modus:

java -cp "CMDSolver.jar;libs/CASprzak.jar" cmd.CASSolver \
    -I:simple.cas \
    -S:NEWTON_SPARSE_ARMIJO \
    -DI
3
Ausgabe lesen

CMDSolver schreibt result.out ins Arbeitsverzeichnis und gibt die Konvergenztabelle auf der Konsole aus:

// Konsole:
INFO: Starting Newton-Raphson + Armijo line search [n=2, tol=1.00e-07]
INFO: Converged at iter 2: fsum=1.234e-14 < tol=1.00e-07

// result.out:
# NAME; VALUE; LOWER; UPPER; UNIT; STATUS; DESCRIPTION
X; 7.000000e+00; -100.0; 100.0; -; FREE; Unbekannte X
Y; 3.000000e+00; -100.0; 100.0; -; FREE; Unbekannte Y
4
Startwerte anpassen (optional)

Erstelle eine -U:-Datei um Startwerte oder Bounds zur Laufzeit zu überschreiben — ohne die CAS-Datei zu ändern:

// overrides.txt
Name:X; Value:5.0; Status:Free; Lower:-200.0; Upper:200.0; Unit:-; Descr:Override
java -cp ... cmd.CASSolver -I:simple.cas -U:overrides.txt

Alle Solver vergleichen

java -cp "CMDSolver.jar;libs/CASprzak.jar" cmd.CASSolver -I:simple.cas -TEST

Einstiegspfad 2 — SolverAPI (Einbettung)

Wähle diesen Pfad wenn: Du CMDSolver in ein bestehendes Java-Framework einbetten willst — ohne CLI, ohne argv, programmatisch steuerbar.
1
Einfachster Aufruf — Modell laden und lösen
import cmd.SolverAPI;
import cmd.SolverResult;

// Minimal — 3 Zeilen
SolverAPI api = new SolverAPI();
api.loadModel("model.cas");
SolverResult result = api.solve();

if (result.isConverged()) {
    double pt = result.getValue("PARTM.F060.PT");
    System.out.println("PT = " + pt + " Pa");
}
2
Method-Chaining — vollständige Konfiguration
SolverResult result = new SolverAPI()
    .loadModel("nozzle.cas")
    .setSolverType(SolverType.NEWTON_SPARSE_ARMIJO)
    .setTolerance(1e-8)
    .setMaxIterations(150)
    .setVariableFixed("AMB.PS", 98136.5)   // Randbedingung setzen
    .setVariableValue("PARTM.F060.TT", 800.0) // Startwert
    .setDiagnoseMode(true)                    // Startwertoptimierung
    .solve();
3
Fehlerbehandlung — ParseErrors und Konvergenzfehler
SolverResult result = api.solve();

// Parse-Fehler prüfen (CAS-Datei korrekt?)
if (result.hasParseErrors()) {
    for (ParseError e : result.getParseErrors()) {
        System.err.println("[" + e.getSeverity() + "] Line "
            + e.getLineNumber() + ": " + e.getMessage());
    }
    return;
}

// Konvergenz prüfen
if (!result.isConverged()) {
    System.err.println("Nicht konvergiert: " + result.getErrorMessage());
    System.err.println("Letzte fsum: " + result.getFinalResidual());
    return;
}

// Ergebnis auslesen
Map<String, Double> values = result.getAllValues();
values.forEach((name, val) ->
    System.out.printf("%-30s = %.6g%n", name, val));
4
Parameterstudie — mehrere Betriebspunkte
double[] altitudes = {0, 5000, 10000, 15000}; // m

for (double alt : altitudes) {
    SolverResult r = new SolverAPI()
        .loadModel("nozzle.cas")
        .setSolverType(SolverType.BROYDEN_SPARSE)  // schnellster für Serien
        .setVariableFixed("AMB.ALTITUDE", alt)
        .solve();

    if (r.isConverged()) {
        System.out.printf("h=%.0fm: Thrust=%.1f N%n",
            alt, r.getValue("FULLM.THRUST"));
    }
}

Ergebnis ausgeben

MethodeVerwendungBeschreibung
getValue("NAME") Einzelne Variable Gibt Double.NaN wenn nicht vorhanden
hasValue("NAME") Existenzprüfung Vor getValue() aufrufen wenn unsicher
getAllValues() Alle Variablen Gibt unmodifizierbare Map<String, Double> zurück
formatAsString() Vollständige Ausgabe Alle Variablen als formatierter String
writeToFile("result.out") Datei schreiben Semikolon-getrenntes Format
writeToWriter(writer) GUI / Stream Für JTextArea, StringWriter, etc.

GUI-Integration — SolverLogger in JTextArea

// Log-Output in JTextArea umleiten
JTextArea logArea = new JTextArea();
Logger root = Logger.getLogger("apps.eqnParser");
root.addHandler(new Handler() {
    public void publish(LogRecord r) {
        SwingUtilities.invokeLater(() ->
            logArea.append(r.getMessage() + "\n"));
    }
    public void flush() {}
    public void close() {}
});

// Ergebnis in JTextArea
SolverResult result = api.solve();
StringWriter sw = new StringWriter();
result.writeToWriter(sw);
resultArea.setText(sw.toString());
