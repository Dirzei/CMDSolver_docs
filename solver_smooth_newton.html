Theoretischer Kontext

Theoretical context

Das Problem — IF/ELSE-Diskontinuitäten

The problem — IF/ELSE discontinuities

Physikalische CAS-Dateien enthalten Regime-Übergänge wie IF (NPR >= NPR_K) für den Wechsel zwischen Unterschall- und Schallbetrieb. Diese erzeugen Sprünge im Jacobian: an der Regime-Grenze wechselt die Ableitungsformel abrupt. Der Newton-Schritt Δx = −J⁻¹·F zeigt dort in die falsche Richtung — Armijo-Linienssuche scheitert, der Solver divergiert.

Physical CAS files contain regime transitions such as IF (NPR >= NPR_K) for switching between subsonic and sonic operation. These create jumps in the Jacobian: at the regime boundary the derivative formula switches abruptly. The Newton step Δx = −J⁻¹·F then points in the wrong direction — Armijo line search fails, the solver diverges.

Die Lösung — Smooth-Newton Prinzip

The solution — Smooth-Newton principle

Der entscheidende Befund: Der Jacobian ist die Ursache — nicht der Solver selbst. Smooth-Newton verwendet deshalb einen glatten Jacobian Jsmooth für die Newton-Richtung, aber das exakte Residual Fifelse für die Konvergenzprüfung:

The key finding: the Jacobian is the root cause — not the solver itself. Smooth-Newton therefore uses a smooth Jacobian Jsmooth for the Newton direction, but the exact residual Fifelse for convergence checking:

Jacobian: Jsmooth = ∂Fsmooth/∂x ← C¹-stetig, korrekter Newton-Schritt
Residual: F(x) = Fifelse(x) ← exakt (IF/ELSE), für Konvergenzprüfung
Schritt: Δx = −Jsmooth⁻¹ · Fifelse(x)

Das Residual bleibt physikalisch exakt — nur die Suchrichtung wird verbessert. Kein Kompromiss an Genauigkeit, erheblicher Gewinn an Robustheit.

The residual stays physically exact — only the search direction is improved. No compromise on accuracy, significant gain in robustness.

smooth_max — die Kernoperationthe core operation

Logistikfunktion (Sigmoid)

Logistic function (sigmoid)

Der harte binäre Schalter cond(x) ∈ {0,1} wird durch die Logistikfunktion σ approximiert:

The hard binary switch cond(x) ∈ {0,1} is approximated by the logistic function σ:

σ(z; β) = 1 / (1 + e^{−β·z}) z = A(x) − B(x), β = Steilheitsparameter
σ(z) → 1 wenn z → +∞ (Bedingung sicher erfüllt)
σ(z) → 0 wenn z → −∞ (Bedingung sicher nicht erfüllt)
σ(0) = 0.5 genau am Umschaltpunkt

smooth_max(a, b; β)

Die zentrale Operation — approximiert max(a, b) stetig:

The core operation — continuously approximates max(a, b):

smooth_max(a, b; β) = σ(β·(a−b)) · a + (1 − σ(β·(a−b))) · b
a >> b → σ → 1 → smooth_max → a = max(a,b) ✓
a << b → σ → 0 → smooth_max → b = max(a,b) ✓
a ≈ b → σ ≈ 0.5 → smooth_max → (a+b)/2 glatter Übergang
Maximaler Fehler am Umschaltpunkt: |a−b|/4 ≤ 2/β
Für β=200: Fehler ≈ 0.01 (1% bei normierten Größen)

Glatte Residualfunktion

Smooth residual function

Eine konditionale Gleichung F(x) = Fif(x) oder Felse(x) mit Bedingung A(x) ≥ B(x) wird ersetzt durch:

A conditional equation F(x) = Fif(x) or Felse(x) with condition A(x) ≥ B(x) is replaced by:

Fsmooth(x; β) = σ(β·(A(x)−B(x))) · Fif(x)
+ (1 − σ(β·(A(x)−B(x)))) · Felse(x)
Gradient (Jacobian-Eintrag):
∂Fsmooth/∂xⱼ = β·σ(1−σ)·∂z/∂xⱼ·(Fif−Felse) ← Interpolationsterm (fehlt in Jifelse!)
+ σ·∂Fif/∂xⱼ ← IF-Zweig-Anteil
+ (1−σ)·∂Felse/∂xⱼ ← ELSE-Zweig-Anteil

function smooth_newton_solve(F, x₀, β, tol, maxIter):

    // ── Einmalig: Zero-Constraints berechnen ──
    zeroConstraints ← computeZeroPropagatedAliases(sysData, x₀)

    x ← InitGuessApplier(x₀)       // Startwerte aus INITIALIZE-Block

    for k = 0 to maxIter:

        // ── Exaktes Residual (IF/ELSE original) ──
        f ← F_ifelse(x)               // für Konvergenzprüfung + Armijo

        if ||f|| < tol: return x    // konvergiert!

        // ── Jacobian mit Sigmoid-Glättung (Kern-Unterschied!) ──
        J ← buildJacobianSmooth(F, x, β)
            // für jede Gleichung i, jede Variable j:
            //   J[i][j] = (calcFuncSmooth(x+h·ej) − calcFuncSmooth(x)) / h
            //   isConditional → SmoothEvaluator (Sigmoid)
            //   isStructConditional → calcFunc() unverändert
            //   normal/CALL → calcFunc() unverändert

        // ── Newton-Schritt ──
        Δx ← −J⁻¹ · f

        // ── Armijo-Liniensuche mit exaktem Residual ──
        α ← 1.0
        while α > α_min:
            x_try ← x + α · Δx
            if ||F_ifelse(x_try)|| ≤ ||f|| · (1 − c₁·α):
                break
            α ← α · ρ

        // ── Update + Projektion ──
        x ← x + α · Δx
        x ← PhysicalProjector(x, bounds, zeroConstraints)

    return x  // maxIter erreicht
function smooth_newton_solve(F, x₀, β, tol, maxIter):

    // ── Once: compute zero-constraints ──
    zeroConstraints ← computeZeroPropagatedAliases(sysData, x₀)

    x ← InitGuessApplier(x₀)       // starting values from INITIALIZE block

    for k = 0 to maxIter:

        // ── Exact residual (original IF/ELSE) ──
        f ← F_ifelse(x)               // for convergence check + Armijo

        if ||f|| < tol: return x    // converged!

        // ── Jacobian with sigmoid smoothing (key difference!) ──
        J ← buildJacobianSmooth(F, x, β)
            // for each equation i, variable j:
            //   J[i][j] = (calcFuncSmooth(x+h·ej) − calcFuncSmooth(x)) / h
            //   isConditional → SmoothEvaluator (sigmoid)
            //   isStructConditional → calcFunc() unchanged
            //   normal/CALL → calcFunc() unchanged

        // ── Newton step ──
        Δx ← −J⁻¹ · f

        // ── Armijo line search with exact residual ──
        α ← 1.0
        while α > α_min:
            x_try ← x + α · Δx
            if ||F_ifelse(x_try)|| ≤ ||f|| · (1 − c₁·α):
                break
            α ← α · ρ

        // ── Update + projection ──
        x ← x + α · Δx
        x ← PhysicalProjector(x, bounds, zeroConstraints)

    return x  // maxIter reached

Grenzen & Einschränkungen

Limits & Constraints

Keine vollständig quadratische Konvergenz. Not fully quadratic convergence. Da Jsmooth ≠ ∂Fifelse/∂x gibt es einen Konsistenzfehler O(1/β). Für β=200: Fehler ≈ 0.01. In der Praxis konvergiert Smooth-Newton superlinear (nicht quadratisch). Since Jsmooth ≠ ∂Fifelse/∂x there is a consistency error O(1/β). For β=200: error ≈ 0.01. In practice, Smooth-Newton converges superlinearly (not quadratically).
Kein Gewinn bei rein-stetigen Systemen. No gain on purely continuous systems. Ohne physikalische IF/ELSE-Conditionals ist Smooth-Newton identisch zu Newton-Armijo (SmoothEvaluator gibt calcFunc() zurück). Kein Overhead, aber auch kein Gewinn. Without physical IF/ELSE conditionals, Smooth-Newton is identical to Newton-Armijo (SmoothEvaluator returns calcFunc()). No overhead, but also no gain.
Benutzer-Switches bleiben IF/ELSE. User switches stay as IF/ELSE. IF (FFSWITCH1.EQ.0) (structConditional) wird nicht geglättet — der Benutzer will entweder AN oder AUS, kein Dazwischen. IF (FFSWITCH1.EQ.0) (structConditional) is not smoothed — the user wants either ON or OFF, not something in between.
