Theoretischer Kontext

Theoretical context

Grundidee — allgemein verständlich

Idea — in plain words

Das Newton-Raphson-Verfahren löst ein nichtlineares Gleichungssystem F(x) = 0 iterativ. Die Idee ist einfach: Man approximiert die krumme Funktion F lokal durch eine Gerade (die Tangente) und berechnet wo diese Gerade die Nulllinie schneidet. Dieser Schnittpunkt ist der nächste Versuchspunkt. Das wiederholt man bis die Funktion nahe genug an Null ist.

Newton-Raphson solves a nonlinear equation system F(x) = 0 iteratively. The idea is simple: locally approximate the curved function F by a straight line (the tangent) and compute where that line crosses zero. That intersection is the next trial point. Repeat until the function is close enough to zero.

Die Armijo-Liniensuche ist eine Sicherheitsbremse: Der reine Newton-Schritt kann manchmal zu groß sein und die Lösung überspringen. Armijo testet ob der volle Schritt das Residuum tatsächlich verkleinert — wenn nicht, wird er halbiert und nochmal getestet, bis er "gut genug" ist.

The Armijo line search is a safety brake: the raw Newton step can sometimes be too large and overshoot the solution. Armijo tests whether the full step actually reduces the residual — if not, it is halved and re-tested until it is "good enough".

Jacobi-Matrix in CMDSolver

Jacobian matrix in CMDSolver

Die Jacobi-Matrix wird symbolisch berechnet — nicht numerisch via finite Differenzen. CASprzak differenziert jede Gleichung analytisch nach jeder Variable. Das ist exakter und schneller als numerische Näherungen. Der Aufbau erfolgt parallel über mehrere Threads (AbstractSolver.buildJacobian()).

The Jacobian is computed symbolically — not numerically via finite differences. CASprzak differentiates every equation analytically with respect to every variable. This is more accurate and faster than numerical approximations. Assembly is parallelized over several threads (AbstractSolver.buildJacobian()).

Die Konditionszahl κ der Jacobi wird in jedem Schritt geschätzt. Bei κ > 10¹² wird eine Warnung ausgegeben und der Wechsel zu Levenberg-Marquardt empfohlen.

The condition number κ of the Jacobian is estimated at every step. When κ > 10¹² a warning is issued and switching to Levenberg-Marquardt is recommended.

Konvergenzrate

Convergence rate

In der Nähe der Lösung konvergiert Newton-Raphson quadratisch: Wenn der Fehler im Schritt k gleich ε ist, ist er im Schritt k+1 proportional zu ε². Das erklärt warum typische Systeme in 3-5 Iterationen konvergieren — jede Iteration verdoppelt ungefähr die Anzahl korrekter Dezimalstellen.

Near the solution, Newton-Raphson converges quadratically: if the error at step k is ε, then at step k+1 it is proportional to ε². This is why typical systems converge in 3–5 iterations — each iteration roughly doubles the number of correct decimal digits.

Pseudocode

Pseudocode

function newton_armijo_solve(F, x₀, tol, maxIter):

    x ← InitGuessApplier(x₀)       // Startwerte aus INITIALIZE-Block
    
    for k = 0 to maxIter:
    
        // ── Jacobi aufbauen (parallel, symbolisch) ──
        J ← buildJacobian(F, x)     // ∂Fᵢ/∂xⱼ via CASprzak
        f ← F(x)                    // Residuumsvektor
        
        // ── Konditionszahl schätzen ──
        κ ← estimateCondition(J)
        if κ > 1e12: LOG.warning("ill-conditioned — consider LM")
        
        // ── Newton-Schritt ──
        Δx ← −J⁻¹ · f              // lineares System lösen
        
        // ── Armijo-Liniensuche ──
        α ← 1.0                     // voller Schritt
        slope ← −||f||²             // Abstiegsrichtung
        while α > α_min:
            x_try ← x + α · Δx
            if ||F(x_try)||² ≤ ||f||² + c₁·α·slope:
                break            // Armijo-Bedingung erfüllt
            α ← α · ρ              // Schritt halbieren (ρ = 0.5)
        
        // ── Update ──
        x ← x + α · Δx
        x ← PhysicalProjector(x)   // Bounds enforzen
        
        // ── Konvergenzprüfung ──
        fsum ← Σ|Fᵢ(x)|
        if fsum < tol:
            return CONVERGED, x, k, fsum
    
    return NOT_CONVERGED, x, maxIter, fsum
function newton_armijo_solve(F, x₀, tol, maxIter):

    x ← InitGuessApplier(x₀)       // starting values from INITIALIZE block
    
    for k = 0 to maxIter:
    
        // ── Build Jacobian (parallel, symbolic) ──
        J ← buildJacobian(F, x)     // ∂Fᵢ/∂xⱼ via CASprzak
        f ← F(x)                    // residual vector
        
        // ── Estimate condition number ──
        κ ← estimateCondition(J)
        if κ > 1e12: LOG.warning("ill-conditioned — consider LM")
        
        // ── Newton step ──
        Δx ← −J⁻¹ · f              // solve linear system
        
        // ── Armijo line search ──
        α ← 1.0                     // full step
        slope ← −||f||²             // descent direction
        while α > α_min:
            x_try ← x + α · Δx
            if ||F(x_try)||² ≤ ||f||² + c₁·α·slope:
                break            // Armijo condition met
            α ← α · ρ              // halve step (ρ = 0.5)
        
        // ── Update ──
        x ← x + α · Δx
        x ← PhysicalProjector(x)   // enforce bounds
        
        // ── Convergence check ──
        fsum ← Σ|Fᵢ(x)|
        if fsum < tol:
            return CONVERGED, x, k, fsum
    
    return NOT_CONVERGED, x, maxIter, fsum
Armijo-Parameter (Defaults): α_init = 1.0 · α_min = 1e-8 · c₁ = 1e-4 · ρ = 0.5 (Halbierung)

Bekannte Grenzen

Known limits

Singuläre Jacobi: Wenn J singulär ist (κ → ∞) wirft der Solver eine SingularJacobianException. Das passiert typischerweise wenn zwei Gleichungen identisch sind oder eine Variable in keiner Gleichung vorkommt.
Singular Jacobian: when J is singular (κ → ∞) the solver throws a SingularJacobianException. This typically happens when two equations are identical or a variable does not appear in any equation.
Lokale Konvergenz: Newton-Raphson konvergiert nur lokal — der Startvektor muss nahe genug an der Lösung sein. Bei schlechten Startwerten kann der Solver divergieren oder in einer falschen Lösung stecken bleiben. -DI (Diagnose-Modus) verbessert den Startvektor automatisch.
Local convergence: Newton-Raphson only converges locally — the starting vector must lie close enough to the solution. With poor starting values the solver can diverge or get stuck in a wrong solution. -DI (diagnostic mode) improves the starting vector automatically.
Dichte Jacobi: Die Matrixinversion kostet O(n³) — für große Systeme (n > 200) ist NEWTON_SPARSE_ARMIJO deutlich effizienter.
Dense Jacobian: the matrix inversion costs O(n³) — for large systems (n > 200) NEWTON_SPARSE_ARMIJO is significantly more efficient.
PhysicalProjector Interaktion: Wenn der Projektor aggressiv eingreift (viele Bounds-Verletzungen) kann das die Konvergenz verlangsamen, weil der effektive Schritt vom Newton-Schritt abweicht.
PhysicalProjector interaction: when the projector intervenes aggressively (many bounds violations), convergence can slow down because the effective step deviates from the Newton step.
