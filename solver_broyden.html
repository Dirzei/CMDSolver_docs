Grundidee — allgemein verständlich

Core idea — in plain terms

Bei Newton-Verfahren wird in jeder Iteration die vollständige Jacobi-Matrix neu berechnet — das ist teuer. Broyden fragt: "Können wir die Jacobi aus dem vorherigen Schritt anpassen statt sie neu zu berechnen?"

In Newton methods the full Jacobian is recomputed every iteration — that's expensive. Broyden asks: "Can we adjust the Jacobian from the previous step instead of rebuilding it?"

Die Antwort: Ja — durch einen Rang-1-Update. Man berechnet wie sich F zwischen zwei Punkten verändert hat und korrigiert die Jacobi-Approximation minimal so dass sie mit dieser Beobachtung konsistent ist. Das kostet O(n²) statt O(n³) für einen vollständigen Neuaufbau.

The answer: yes — via a rank-1 update. We compute how F changed between two points and minimally correct the Jacobian approximation so it remains consistent with that observation. That costs O(n²) instead of O(n³) for a full rebuild.

Reset-Mechanismus

Reset mechanism

Broyden akkumuliert Approximationsfehler über die Iterationen. CMDSolver implementiert daher einen automatischen Reset: Nach resetInterval Iterationen oder wenn die Konditionszahl κ einen Schwellwert überschreitet, wird die Jacobi vollständig neu berechnet. Das verhindert Divergenz durch akkumulierte Fehler.

Broyden accumulates approximation error over iterations. CMDSolver therefore implements an automatic reset: after resetInterval iterations, or when the condition number κ exceeds a threshold, the Jacobian is fully rebuilt. This prevents divergence due to accumulated error.

Pseudocode

Pseudocode

function broyden_solve(F, x₀, tol, maxIter, resetInterval):
    x ← InitGuessApplier(x₀)
    J ← buildJacobian(F, x)    // vollständiger Aufbau beim Start// full build at start
    Jinv ← inverse(J)

    for k = 0 to maxIter:
        f ← F(x)

        // ── Newton-Schritt mit approximierter Jacobi ──// ── Newton step with approximated Jacobian ──
        Δx ← −Jinv · f

        // ── Armijo-Liniensuche ──// ── Armijo line search ──
        α ← armijo_search(x, Δx, F)

        x_new ← x + α · Δx
        f_new ← F(x_new)

        // ── Broyden Rang-1-Update ──// ── Broyden rank-1 update ──
        if k % resetInterval != 0 and κ(J) < κ_reset:
            Δf ← f_new − f
            J ← J + (Δf − J·Δx) · Δxᵀ / ||Δx||²  // O(n²)// O(n²)
            Jinv ← update_inverse(Jinv, Δx, Δf)
        else:
            J ← buildJacobian(F, x_new)             // vollständiger Reset// full reset
            Jinv ← inverse(J)

        x ← x_new
        x ← PhysicalProjector(x)
        fsum ← Σ|Fᵢ(x)|
        if fsum < tol: return CONVERGED, x, k, fsum

    return NOT_CONVERGED, x, maxIter, fsum

Bekannte Grenzen

Known Limitations

Akkumulierte Fehler: Die Jacobi-Approximation degradiert über viele Iterationen. Der Reset-Mechanismus begrenzt das, kann es aber nicht vollständig vermeiden. Bei sehr nichtlinearen Systemen häufiger Reset empfohlen.
Accumulated error: the Jacobian approximation degrades over many iterations. The reset mechanism limits this but cannot fully prevent it. For strongly nonlinear systems, more frequent resets are recommended.
Superlineare Konvergenz: Broyden konvergiert superlinear statt quadratisch — mehr Iterationen als Newton bei gleicher Genauigkeit.
Superlinear convergence: Broyden converges superlinearly, not quadratically — more iterations than Newton at the same accuracy.
