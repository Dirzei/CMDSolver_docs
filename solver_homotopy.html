Arc-Length Continuation

Klassische Continuation: verfolgt einen glatten Lösungspfad von einem einfachen Startproblem zum Zielproblem mit fester t-Parametrisierung. Predictor-Korrektor-Schema mit innerem Newton-/LM-Solver. Verwandte Solver: ARC_LENGTH (Bogen-Längen, experimental) und ADAPTIVE_LAMBDA (Wrapper, Phase 1 produktiv).

Classical continuation: follows a smooth solution path from a simple starting problem to the target problem with fixed t-parametrization. Predictor-corrector scheme with an inner Newton or LM solver. Related solvers: ARC_LENGTH (arc-length, experimental) and ADAPTIVE_LAMBDA (wrapper, Phase 1 in production).

Theoretischer Kontext

Theoretical Context

Grundidee — allgemein verständlich

Core idea — in plain terms

Alle anderen Solver starten direkt am Problem F(x) = 0 und können divergieren wenn der Startvektor zu weit von der Lösung entfernt ist. Homotopie geht anders: Man baut eine Brücke vom einfachen zum schwierigen Problem.

All other solvers tackle F(x) = 0 directly and can diverge if the starting vector is too far from the solution. Homotopy is different: it builds a bridge from the easy to the hard problem.

Stell dir vor du willst einen Berggipfel erreichen (die Lösung) aber weißt nicht wie. Homotopie beginnt in einem flachen Tal (dem Startproblem) und folgt einem markierten Wanderweg (dem Homotopie-Pfad) schrittweise hinauf. Jeder Schritt ist klein genug um lokal lösbar zu sein.

Picture wanting to reach a mountain summit (the solution) but not knowing how. Homotopy starts in a flat valley (the starting problem) and follows a marked trail (the homotopy path) up step by step. Each step is small enough to be solvable locally.

Homotopie-Funktion:Homotopy function:
H(x, t) = t·F(x) + (1−t)·(x − x₀) = 0
t = 0: H(x,0) = x − x₀ = 0 → Lösung: x = x₀ (trivial)
t = 0: H(x,0) = x − x₀ = 0 → Solution: x = x₀ (trivial)
t = 1: H(x,1) = F(x) = 0 → Originalproblem
t = 1: H(x,1) = F(x) = 0 → Original problem
Arc-Length Parametrisierung:Arc-length parametrization:
s = Bogenlänge entlang des Pfades (x(s), t(s))
s = arc length along the path (x(s), t(s))
Vermeidet Singularitäten an Wendepunkten des Pfades
Avoids singularities at turning points of the path

Prädiktor-Korrektor Strategie

Predictor-corrector strategy

CMDSolver implementiert eine Prädiktor-Korrektor-Methode:

CMDSolver implements a predictor-corrector method:

Prädiktor: Schätzt den nächsten Punkt auf dem Pfad durch lineare Extrapolation entlang des Tangentenvektors (Euler-Prädiktor).

Predictor: estimates the next point on the path by linear extrapolation along the tangent vector (Euler predictor).

Korrektor: Verwendet einen inneren Newton-basierten Solver um H(x, t_next) = 0 exakt zu lösen. Standard-Korrektor: NEWTON_ARMIJO. Bei schlecht konditionierten Systemen empfohlen: LEVENBERG_MARQUARDT.

Corrector: uses an inner Newton-based solver to solve H(x, t_next) = 0 exactly. Default corrector: NEWTON_ARMIJO. For ill-conditioned systems: LEVENBERG_MARQUARDT recommended.

Adaptive Schrittweite

Adaptive step size

Die Schrittweite ds wird adaptiv angepasst: Bei erfolgreicher Korrektur wird ds vergrößert (schneller vorankommen), bei Stagnation oder Konvergenzschwierigkeiten wird ds halbiert.

The step size ds is adapted dynamically: after a successful correction ds is enlarged (advance faster); on stagnation or convergence difficulties ds is halved.

fsum = NaN: Der Homotopie-Solver gibt kein fsum über den normalen Kanal aus — er hat eine eigene Konvergenzprüfung über t → 1. NaN bedeutet "nicht verfügbar", nicht "Fehler". Status CONVERGED ist maßgeblich.
fsum = NaN: the homotopy solver does not report fsum over the standard channel — it has its own convergence check via t → 1. NaN means "not available", not "error". The CONVERGED status is authoritative.

Pseudocode

Pseudocode

function homotopy_solve(F, x₀, steps, ds_init, innerSolver):
    x ← x₀
    t ← 0.0
    ds ← ds_init
    J₀ ← buildJacobian(F, x₀)     // Anfangspunkt// initial point

    while t < 1.0:
        tNext ← min(t + ds, 1.0)

        // ── Prädiktor (Euler entlang Tangente) ──// ── Predictor (Euler along tangent) ──
        tangent ← computeTangent(J₀, x, t)
        x_predict ← x + ds · tangent

        // ── Korrektor (innerer Solver) ──// ── Corrector (inner solver) ──
        H_system ← buildHomotopySystem(F, x₀, tNext)
        result ← innerSolver.solve(H_system, x_predict)

        if result.converged:
            x ← result.solution
            t ← tNext
            ds ← min(ds · 1.5, ds_max)  // vergrößern// enlarge
        else:
            ds ← ds / 2.0               // halbieren// halve
            if ds < ds_min:
                return STAGNATION, x, t

    return CONVERGED, x, t=1.0
Innerer Solver: Standard ist NEWTON_ARMIJO. Bei schlecht konditionierten Systemen empfohlen: -SH:INNER=LEVENBERG_MARQUARDT
Inner solver: default is NEWTON_ARMIJO. For ill-conditioned systems: -SH:INNER=LEVENBERG_MARQUARDT recommended.

Bekannte Grenzen

Known Limitations

Geschwindigkeit: Homotopie ist langsamer als direkte Solver — jeder Schritt auf dem Pfad erfordert einen vollständigen inneren Solver-Lauf. Nur verwenden wenn Newton und LM scheitern.
Speed: homotopy is slower than direct solvers — each step on the path requires a full inner solver run. Use only when Newton and LM fail.
Pfad-Singularitäten: Wenn der Homotopie-Pfad durch eine Singularität verläuft (Wendepunkt, Bifurkation), kann der Solver stagnieren. Die adaptive Schrittweite erkennt Stagnation und meldet sie.
Path singularities: when the homotopy path passes through a singularity (turning point, bifurcation), the solver may stagnate. The adaptive step size detects stagnation and reports it.
fsum = NaN: Normal — der Homotopie-Solver gibt kein fsum über den Standard-Kanal aus. CONVERGED-Status ist maßgeblich.
fsum = NaN: normal — the homotopy solver does not report fsum over the standard channel. The CONVERGED status is authoritative.
