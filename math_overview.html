Das Problem — F(x) = 0

The Problem — F(x) = 0

In thermodynamischen Modellen wie den Triebwerks- und Düsenmodellen von CMDSolver entstehen nichtlineare algebraische Gleichungssysteme. Jede Gleichung beschreibt eine physikalische Beziehung zwischen Variablen wie Druck, Temperatur, Massenstrom oder Geometriegrößen.

Thermodynamic models such as CMDSolver's engine and nozzle models give rise to nonlinear algebraic equation systems. Every equation describes a physical relationship between variables such as pressure, temperature, mass flow, or geometric quantities.

Gesucht:Find: x* ∈ ℝⁿ so dass F(x*) = 0
wobei:where:
F: ℝⁿ → ℝⁿ // n Gleichungen, n Unbekannte// n equations, n unknowns
x = (x₁, …, xₙ)ᵀ // freie Variablen (Druck, Temp, ...)// free variables (pressure, temp, ...)
Fᵢ(x) = 0 // i-te Gleichung als Residuum// i-th equation as residual
Beispiel (Düsengleichung):Example (nozzle equation):
F₁: FULLM.F080.W − FULLM.F060.W = 0 // Massenerhaltung// mass conservation
F₂: FULLM.F080.PT − FULLM.F060.PT·η = 0 // Druckverhältnis// pressure ratio
F₃: FULLM.HTMAX − f(PT, TT, W, ...) = 0 // Thermodynamik// thermodynamics

Implementierte Verfahren

Implemented Methods

1. Newton-Raphson (mit Varianten)

1. Newton-Raphson (with Variants)

Die Familie der Newton-Verfahren linearisiert F lokal durch die Jacobi-Matrix J und löst das entstehende lineare System. Unterschiede liegen in der Lösung des linearen Systems (dicht vs. sparse) und der Schrittdämpfung.

The Newton family linearizes F locally via the Jacobian matrix J and solves the resulting linear system. Variants differ in how the linear system is solved (dense vs. sparse) and in step damping.

2. Levenberg-Marquardt

2. Levenberg-Marquardt

LM kombiniert Newton-Raphson mit Gradientenabstieg über einen adaptiven Dämpfungsparameter λ. Bei großem λ verhält sich LM wie Gradientenabstieg (robust, langsam), bei kleinem λ wie Newton (schnell, lokal). Besonders geeignet für schlecht konditionierte Systeme.

LM combines Newton-Raphson with gradient descent via an adaptive damping parameter λ. For large λ, LM behaves like gradient descent (robust, slow); for small λ, like Newton (fast, local). Especially well-suited for ill-conditioned systems.

LM-System:LM system: (JᵀJ + λI) · Δx = −Jᵀ F(x)
// λ groß → Gradientenabstieg (stabiler)// λ large → gradient descent (more stable)
// λ klein → Newton-Schritt (schneller)// λ small → Newton step (faster)
// λ wird adaptiv nach Fortschritt angepasst// λ is adapted based on progress

3. Broyden Quasi-Newton

3. Broyden Quasi-Newton

Broyden aktualisiert die Jacobi-Approximation durch einen Rang-1-Update statt sie neu aufzubauen. Das spart Rechenzeit pro Iteration — besonders vorteilhaft wenn die Jacobi-Berechnung teuer ist. Zwei Varianten: mit dichter und mit GSPAR Sparse-LU.

Broyden updates the Jacobian approximation via a rank-1 update instead of rebuilding it. This saves computation per iteration — especially advantageous when Jacobian assembly is expensive. Two variants: with dense and with GSPAR sparse LU.

Broyden-Update:Broyden update:
Jₖ₊₁ = Jₖ + (Δf − Jₖ·Δx) · ΔxᵀT / ||Δx||²
// Rang-1-Korrektur — O(n²) statt O(n³) für Neuaufbau// Rank-1 correction — O(n²) instead of O(n³) for full rebuild

4. Homotopie (Arc-Length Continuation)

4. Homotopy (Arc-Length Continuation)

Homotopie löst nicht direkt F(x) = 0, sondern konstruiert einen glatten Pfad von einem einfachen Startproblem H(x,0) = 0 zum Zielproblem H(x,1) = F(x) = 0. Besonders geeignet wenn der Startvektor weit von der Lösung entfernt ist oder bei stark nichtlinearen Systemen.

Homotopy does not solve F(x) = 0 directly but constructs a smooth path from a simple starting problem H(x,0) = 0 to the target H(x,1) = F(x) = 0. Especially useful when the starting vector is far from the solution or on strongly nonlinear systems.

Homotopie-Funktion:Homotopy function:
H(x, t) = t·F(x) + (1−t)·F₀(x) = 0, t ∈ [0, 1]
// t=0: einfaches Startproblem (Startwerte)// t=0: simple starting problem (initial values)
// t=1: Original-Problem F(x) = 0// t=1: original problem F(x) = 0
// Arc-Length: Pfad wird nach Bogenlänge parametrisiert// Arc-length: path is parametrized by arc length

Weitere Verfahren (nicht implementiert)

Other Methods (not implemented)

Hinweis: Die folgenden Verfahren sind für thermodynamische Gleichungssysteme prinzipiell geeignet. Sie sind in CMDSolver nicht implementiert, könnten aber für spezielle Anwendungsfälle relevant sein.
Note: The following methods are in principle suitable for thermodynamic equation systems. They are not implemented in CMDSolver, but could be relevant for special use cases.

Trust-Region Methoden

Trust-Region Methods

Ähnlich wie LM, aber mit expliziter Schrittweitenkontrolle über einen "Vertrauensbereich" (Trust-Region) Δ. Der Newton-Schritt wird auf eine Kugel mit Radius Δ beschränkt. Δ wird adaptiv angepasst basierend auf dem Verhältnis von vorhergesagtem zu tatsächlichem Fortschritt.

Similar to LM but with explicit step-size control via a "trust region" Δ. The Newton step is restricted to a ball of radius Δ. Δ is adapted based on the ratio of predicted to actual progress.

Vorteil gegenüber LM: Geometrisch intuitiveres Modell, bessere theoretische Konvergenzeigenschaften. Standard in modernen Optimierungsbibliotheken (z.B. MINPACK, SciPy).

Advantage over LM: Geometrically more intuitive model, better theoretical convergence properties. Standard in modern optimization libraries (e.g., MINPACK, SciPy).

Dogleg-Verfahren

Dogleg Method

Kombination aus Newton-Schritt und Cauchy-Punkt (steilstem Abstieg) innerhalb der Trust-Region. Berechnet einen "geknickten" Pfad (Dogleg) zwischen beiden. Effizienter als reines Trust-Region bei gut konditionierten Systemen.

Combination of the Newton step and the Cauchy point (steepest descent) inside the trust region. Computes a "bent" path (dogleg) between the two. More efficient than pure trust-region on well-conditioned systems.

GMRES / Krylov-Unterraum Methoden

GMRES / Krylov Subspace Methods

Für sehr große Systeme (n > 10.000) ist selbst GSPAR Sparse-LU zu teuer. GMRES (Generalized Minimal Residual) löst das lineare System J·Δx = −F iterativ ohne die Jacobi explizit zu faktorisieren. Benötigt nur Matrix-Vektor-Produkte J·v.

For very large systems (n > 10,000), even GSPAR sparse LU becomes too expensive. GMRES (Generalized Minimal Residual) solves the linear system J·Δx = −F iteratively without explicitly factorizing the Jacobian. It only requires matrix-vector products J·v.

Relevanz für CMDSolver: Bei den aktuellen Modellgrößen (bis ~500 Gleichungen) nicht nötig. Interessant wenn Netzwerke aus vielen Modulen zu sehr großen Systemen zusammengesetzt werden.

Relevance for CMDSolver: Not needed at current model sizes (up to ~500 equations). Becomes interesting when networks of many modules combine into very large systems.

Anderson Acceleration

Anderson Acceleration

Beschleunigt Fixpunkt-Iterationen x ← G(x) durch Extrapolation aus mehreren vergangenen Iterationswerten. Besonders effektiv bei Systemen die natürlich als Fixpunkt-Iteration formuliert werden können — z.B. bei schwacher Kopplung zwischen Modulen in einer modularen Stream-Architektur.

Accelerates fixed-point iterations x ← G(x) by extrapolating from several past iteration values. Especially effective for systems that can be naturally formulated as a fixed-point iteration — e.g., when there is weak coupling between modules in a modular stream architecture.

Fixpunkt-Iteration (Gauss-Seidel für Gleichungssysteme)

Fixed-Point Iteration (Gauss-Seidel for Equation Systems)

Löst jede Gleichung sequenziell nach einer Variablen auf und iteriert. Konvergiert nur bei kontraktiven Abbildungen — für allgemeine thermodynamische Systeme meist nicht geeignet. War der klassische Ansatz in frühen Prozesssimulatoren (ASPEN, gPROMS vor Version 3).

Solves each equation sequentially for one variable and iterates. Converges only for contractive mappings — usually unsuitable for general thermodynamic systems. Was the classical approach in early process simulators (ASPEN, gPROMS before version 3).

Globales Newton mit Regularisierung

Global Newton with Regularization

Fügt der Jacobi eine Regularisierungsmatrix hinzu: J_reg = J + εI. Einfacher als LM aber weniger theoretisch fundiert. Kann bei sehr schlecht konditionierten Systemen als erster Schritt vor LM nützlich sein.

Adds a regularization matrix to the Jacobian: J_reg = J + εI. Simpler than LM but less theoretically grounded. Can be useful as a first step before LM on very ill-conditioned systems.

Parallele / Verteilte Newton-Verfahren

Parallel / Distributed Newton Methods

Für zukünftige modulare Architekturen: Wenn das System in Teilsysteme (Mixer, Jetpipe, Nozzle) aufgeteilt wird, kann jedes Teilsystem parallel gelöst werden. Block-Newton-Verfahren lösen die Teilsysteme und iterieren über die Kopplung (Stream-Variablen). Relevant für die geplante Stream-Architektur.

For future modular architectures: when the system is split into subsystems (mixer, jet pipe, nozzle), each subsystem can be solved in parallel. Block-Newton methods solve the subsystems and iterate over the coupling (stream variables). Relevant for the planned stream architecture.
