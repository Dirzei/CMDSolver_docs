Nichtlineare Gleichungssysteme

Überblick über numerische Lösungsverfahren für Systeme der Form F(x) = 0 — implementierte und nicht implementierte Methoden im Kontext thermodynamischer Modelle.

Das Problem — F(x) = 0

In thermodynamischen Modellen wie den Triebwerks- und Düsenmodellen von CMDSolver entstehen nichtlineare algebraische Gleichungssysteme. Jede Gleichung beschreibt eine physikalische Beziehung zwischen Variablen wie Druck, Temperatur, Massenstrom oder Geometriegrößen.

Gesucht: x* ∈ ℝⁿ so dass F(x*) = 0
wobei:
F: ℝⁿ → ℝⁿ // n Gleichungen, n Unbekannte
x = (x₁, …, xₙ)ᵀ // freie Variablen (Druck, Temp, ...)
Fᵢ(x) = 0 // i-te Gleichung als Residuum
Beispiel (Düsengleichung):
F₁: FULLM.F080.W − FULLM.F060.W = 0 // Massenerhaltung
F₂: FULLM.F080.PT − FULLM.F060.PT·η = 0 // Druckverhältnis
F₃: FULLM.HTMAX − f(PT, TT, W, ...) = 0 // Thermodynamik

Eigenschaften thermodynamischer Systeme

Die Gleichungssysteme in CMDSolver haben spezifische Eigenschaften die die Wahl des Lösungsverfahrens stark beeinflussen:

EigenschaftTypischer WertAuswirkung
Systemgröße n 12 – 500+ Kleine Systeme: dichte LU. Große: Sparse-Methoden
Nichtlinearitätsgrad Mittel bis hoch Startvektornähe entscheidend für Konvergenz
Konditionszahl κ 10⁶ – 10²⁵ Hohe κ → Newton instabil → LM oder Homotopie
Physikalische Bounds T ≥ 1K, p ≥ 1Pa PhysicalProjector nach jedem Update nötig
Jacobi-Besetzung Dünn besetzt (sparse) Sparse-LU bis zu 10× schneller als dichte LU
Ableitungen Symbolisch (CASprzak) Exakt, kein Finite-Differenzen-Fehler

Klassifikation der Verfahren

Implementierte Verfahren

1. Newton-Raphson (mit Varianten)

Die Familie der Newton-Verfahren linearisiert F lokal durch die Jacobi-Matrix J und löst das entstehende lineare System. Unterschiede liegen in der Lösung des linearen Systems (dicht vs. sparse) und der Schrittdämpfung.

VarianteLineares SystemDämpfungStärke
NEWTON_ARMIJO Dichte LU (MatrixSimple) Armijo-Backtracking Robustheit bei nichtlinearen Systemen
NEWTON_SPARSE GSPAR Sparse-LU Keine Geschwindigkeit bei großen Systemen
NEWTON_SPARSE_ARMIJO GSPAR Sparse-LU Armijo-Backtracking Beste Kombination: schnell + robust

2. Levenberg-Marquardt

LM kombiniert Newton-Raphson mit Gradientenabstieg über einen adaptiven Dämpfungsparameter λ. Bei großem λ verhält sich LM wie Gradientenabstieg (robust, langsam), bei kleinem λ wie Newton (schnell, lokal). Besonders geeignet für schlecht konditionierte Systeme.

LM-System: (JᵀJ + λI) · Δx = −Jᵀ F(x)
// λ groß → Gradientenabstieg (stabiler)
// λ klein → Newton-Schritt (schneller)
// λ wird adaptiv nach Fortschritt angepasst

3. Broyden Quasi-Newton

Broyden aktualisiert die Jacobi-Approximation durch einen Rang-1-Update statt sie neu aufzubauen. Das spart Rechenzeit pro Iteration — besonders vorteilhaft wenn die Jacobi-Berechnung teuer ist. Zwei Varianten: mit dichter und mit GSPAR Sparse-LU.

Broyden-Update:
Jₖ₊₁ = Jₖ + (Δf − Jₖ·Δx) · ΔxᵀT / ||Δx||²
// Rang-1-Korrektur — O(n²) statt O(n³) für Neuaufbau

4. Homotopie (Arc-Length Continuation)

Homotopie löst nicht direkt F(x) = 0, sondern konstruiert einen glatten Pfad von einem einfachen Startproblem H(x,0) = 0 zum Zielproblem H(x,1) = F(x) = 0. Besonders geeignet wenn der Startvektor weit von der Lösung entfernt ist oder bei stark nichtlinearen Systemen.

Homotopie-Funktion:
H(x, t) = t·F(x) + (1−t)·F₀(x) = 0, t ∈ [0, 1]
// t=0: einfaches Startproblem (Startwerte)
// t=1: Original-Problem F(x) = 0
// Arc-Length: Pfad wird nach Bogenlänge parametrisiert

Weitere Verfahren (nicht implementiert)

Hinweis: Die folgenden Verfahren sind für thermodynamische Gleichungssysteme prinzipiell geeignet. Sie sind in CMDSolver nicht implementiert, könnten aber für spezielle Anwendungsfälle relevant sein.

Trust-Region Methoden

Ähnlich wie LM, aber mit expliziter Schrittweitenkontrolle über einen "Vertrauensbereich" (Trust-Region) Δ. Der Newton-Schritt wird auf eine Kugel mit Radius Δ beschränkt. Δ wird adaptiv angepasst basierend auf dem Verhältnis von vorhergesagtem zu tatsächlichem Fortschritt.

Vorteil gegenüber LM: Geometrisch intuitiveres Modell, bessere theoretische Konvergenzeigenschaften. Standard in modernen Optimierungsbibliotheken (z.B. MINPACK, SciPy).

Dogleg-Verfahren

Kombination aus Newton-Schritt und Cauchy-Punkt (steilstem Abstieg) innerhalb der Trust-Region. Berechnet einen "geknickten" Pfad (Dogleg) zwischen beiden. Effizienter als reines Trust-Region bei gut konditionierten Systemen.

GMRES / Krylov-Unterraum Methoden

Für sehr große Systeme (n > 10.000) ist selbst GSPAR Sparse-LU zu teuer. GMRES (Generalized Minimal Residual) löst das lineare System J·Δx = −F iterativ ohne die Jacobi explizit zu faktorisieren. Benötigt nur Matrix-Vektor-Produkte J·v.

Relevanz für CMDSolver: Bei den aktuellen Modellgrößen (bis ~500 Gleichungen) nicht nötig. Interessant wenn Netzwerke aus vielen Modulen zu sehr großen Systemen zusammengesetzt werden.

Anderson Acceleration

Beschleunigt Fixpunkt-Iterationen x ← G(x) durch Extrapolation aus mehreren vergangenen Iterationswerten. Besonders effektiv bei Systemen die natürlich als Fixpunkt-Iteration formuliert werden können — z.B. bei schwacher Kopplung zwischen Modulen in einer modularen Stream-Architektur.

Fixpunkt-Iteration (Gauss-Seidel für Gleichungssysteme)

Löst jede Gleichung sequenziell nach einer Variablen auf und iteriert. Konvergiert nur bei kontraktiven Abbildungen — für allgemeine thermodynamische Systeme meist nicht geeignet. War der klassische Ansatz in frühen Prozesssimulatoren (ASPEN, gPROMS vor Version 3).

Globales Newton mit Regularisierung

Fügt der Jacobi eine Regularisierungsmatrix hinzu: J_reg = J + εI. Einfacher als LM aber weniger theoretisch fundiert. Kann bei sehr schlecht konditionierten Systemen als erster Schritt vor LM nützlich sein.

Parallele / Verteilte Newton-Verfahren

Für zukünftige modulare Architekturen: Wenn das System in Teilsysteme (Mixer, Jetpipe, Nozzle) aufgeteilt wird, kann jedes Teilsystem parallel gelöst werden. Block-Newton-Verfahren lösen die Teilsysteme und iterieren über die Kopplung (Stream-Variablen). Relevant für die geplante Stream-Architektur.

SituationEmpfehlungBegründung

Faustregel: Beginne immer mit NEWTON_SPARSE_ARMIJO. Wechsle zu LM wenn κ-Warnungen auftreten. Verwende Homotopie nur wenn Newton und LM nicht konvergieren — Homotopie ist langsamer aber robuster.
