Architektur der Built-in Funktionen

Architecture of Built-in Functions

Jede thermodynamische Funktion func(args) in BIfunctions hat drei Signaturen die zusammen das Interface für den Solver bilden:

Every thermodynamic function func(args) in BIfunctions has three signatures that together form the solver interface:

Signatur 1 — Residuum:Signature 1 — residual:
dFunc(output, inputs...) = output − func(inputs)
// Gibt 0 wenn output korrekt berechnet wurde // Returns 0 when output is correctly computed
// Wird als Gleichungsresiduum F(x) = 0 verwendet // Used as equation residual F(x) = 0
Signatur 2 — List-Form:Signature 2 — list form:
dFunc(List<Double> values)
// Wrapper für EqnData-Aufruf via Reflection // Wrapper for EqnData invocation via reflection
Signatur 3 — Partielle Ableitung:Signature 3 — partial derivative:
funcDeriv(variables, values, partial)
// Numerische Ableitung ∂(dFunc)/∂x_partial // Numerical derivative ∂(dFunc)/∂x_partial
// Verwendet 5-Punkte-Formel, O(h⁴) Genauigkeit // Uses 5-point formula, O(h⁴) accuracy
Warum diese Struktur? Der Solver braucht für jede Gleichung zwei Dinge: das Residuum F(x) und die Ableitungen ∂F/∂xᵢ für die Jacobi-Matrix. Für Built-in Funktionen kann CASprzak nicht symbolisch differenzieren — daher numerische Ableitungen via funcDeriv.
Why this structure? The solver needs two things per equation: the residual F(x) and the derivatives ∂F/∂xᵢ for the Jacobian. For built-in functions, CASprzak cannot differentiate symbolically — hence numerical derivatives via funcDeriv.

Beispiel — cpOfTNOZ

Example — cpOfTNOZ

// Residuum: cp - cpOfTNOZ(T, WGR, FAR) = 0// Residual: cp - cpOfTNOZ(T, WGR, FAR) = 0
public static double dCpOfTNOZ(double cp, double temp, double wgr, double far) {
    return cp - cpOfTNOZ(temp, wgr, far);
}

// In der CAS-Datei:// In the CAS file:
CALL(NOZ.CP) = pCPOFTNOZ(NOZ.TT, NOZ.WGR, NOZ.FAR);

Ableitungsmethodik — 5-Punkte-Formel

Differentiation — 5-Point Formula

Alle partiellen Ableitungen der Built-in Funktionen werden numerisch berechnet — nicht symbolisch wie bei normalen CAS-Gleichungen. Dies ist nötig weil die thermodynamischen Polynome zu komplex für automatische Differentiation sind.

All partial derivatives of built-in functions are computed numerically — not symbolically like normal CAS equations. This is necessary because the thermodynamic polynomials are too complex for automatic differentiation.

5-Punkte-Formel (O(h⁴) Genauigkeit):5-point formula (O(h⁴) accuracy):
df/dx ≈ [f(x−2h) − 8·f(x−h) + 8·f(x+h) − f(x+2h)] / (12h)
Adaptive Schrittweite:Adaptive step size:
h = adaptiveH(x) = max(|x| · 1e-5, 1e-8)
// Relativ zur Variablengröße — vermeidet Auslöschung // Relative to variable magnitude — avoids cancellation
// Bei x = 200000 Pa: h ≈ 2 Pa (sinnvolle Schrittweite) // For x = 200000 Pa: h ≈ 2 Pa (sensible step)
// Bei x = 0.001: h ≈ 1e-8 (absolute Untergrenze) // For x = 0.001: h ≈ 1e-8 (absolute lower bound)
Genauigkeit: Die 5-Punkte-Formel hat einen Fehler von O(h⁴) — bei h=1e-5·x ist der Ableitungsfehler typisch unter 1e-10 relativ. Das ist ausreichend für Newton-Konvergenz bis fsum ~ 1e-9.
Accuracy: the 5-point formula has an error of O(h⁴) — at h=1e-5·x the derivative error is typically below 1e-10 relative. Sufficient for Newton convergence down to fsum ~ 1e-9.

Schallgeschwindigkeits-Funktionen

Speed-of-Sound Functions

Die Schallgeschwindigkeit in Luft/Abgas hängt von Temperatur, Druck und Gaszusammensetzung ab. CMDSolver verwendet JANAF-Polynome für die thermodynamischen Eigenschaften als Basis.

The speed of sound in air/exhaust depends on temperature, pressure, and gas composition. CMDSolver uses JANAF polynomials as the basis for thermodynamic properties.

Schallgeschwindigkeit (allgemein):Speed of sound (general):
a = √(κ · R · T)
// κ = cp/cv = Isentropenexponent // κ = cp/cv = isentropic exponent
// R = spezifische Gaskonstante [J/kgK] // R = specific gas constant [J/kgK]
// T = Temperatur [K] // T = temperature [K]
JANAF-basierte Berechnung:JANAF-based computation:
cp(T) = Σ aᵢ · Tⁱ (Polynom in T)
cp(T) = Σ aᵢ · Tⁱ (polynomial in T)
κ(T) = cp(T) / (cp(T) − R)
a(T, p, Zusammensetzung) = √(κ · R · T)
a(T, p, composition) = √(κ · R · T)

Enthalpie- und cp-Funktionen

Enthalpy and cp Functions

JANAF-Polynome

JANAF polynomials

JANAF (Joint Army-Navy-Air Force) Thermochemische Tabellen liefern Polynomkoeffizienten für thermodynamische Eigenschaften von Gasen in Abhängigkeit von der Temperatur. CMDSolver verwendet diese für cp(T) und h(T).

JANAF (Joint Army-Navy-Air Force) Thermochemical Tables provide polynomial coefficients for the temperature-dependent thermodynamic properties of gases. CMDSolver uses these for cp(T) and h(T).

JANAF cp-Polynom:JANAF cp polynomial:
cp(T) = R · (a₁ + a₂·T + a₃·T² + a₄·T³ + a₅·T⁴)
JANAF Enthalpie:JANAF enthalpy:
h(T) = R · (a₁·T + a₂·T²/2 + a₃·T³/3 + a₄·T⁴/4 + a₅·T⁵/5 + a₆)
// a₆ = Integrationskonstante (Bildungsenthalpie) // a₆ = integration constant (enthalpy of formation)
Gemischung (mehrere Gaskomponenten):Mixing (multiple gas components):
cp_mix(T) = Σᵢ fᵢ · cpᵢ(T) (massengewichtetes Mittel)
cp_mix(T) = Σᵢ fᵢ · cpᵢ(T) (mass-weighted average)

Atmosphärenmodell — ISA

Atmosphere Model — ISA

Das International Standard Atmosphere (ISA) Modell beschreibt Temperatur und Druck als Funktion der Höhe. CMDSolver implementiert das vollständige ISA-Modell bis 80km Höhe mit 9 Schichten.

The International Standard Atmosphere (ISA) model describes temperature and pressure as a function of altitude. CMDSolver implements the full ISA model up to 80 km altitude with 9 layers.

ISA Temperaturprofil (schichtenweise):ISA temperature profile (layer-wise):
T(h) = Tⱼ + βⱼ · (h − hⱼ) [K]
ISA Druckprofil:ISA pressure profile:
In Gradientschichten (βⱼ ≠ 0):
In gradient layers (βⱼ ≠ 0):
p(h) = pⱼ · (T(h)/Tⱼ)^(−g/(R·βⱼ))
In Isothermschichten (βⱼ = 0):
In isothermal layers (βⱼ = 0):
p(h) = pⱼ · exp(−g·(h−hⱼ)/(R·Tⱼ))
ISA + ΔTISA (Temperaturabweichung vom Standard):ISA + ΔTISA (deviation from standard):
T_eff(h) = T_ISA(h) + ΔTISA

Mach number from the area ratio A/A* (channel divergence ratio). Solves the isentropic flow equation numerically.

Significance for nozzle models: MofCondiRatio is central to all convergent-divergent nozzle calculations (Laval nozzle). The area ratio uniquely determines the Mach number — up to the subsonic/supersonic ambiguity, which is resolved by the boundary conditions.

Hinweis zur Ableitungsqualität: Da Built-in Funktionen numerisch differenziert werden, können an Unstetigkeitsstellen (z.B. ISA-Schichtgrenzen, Phasenübergänge) Ableitungsfehler auftreten. Der Newton-Solver kann dort Konvergenzprobleme zeigen — in diesem Fall Levenberg-Marquardt oder Homotopie verwenden.
Note on derivative quality: because built-in functions are differentiated numerically, derivative errors can occur at discontinuities (e.g., ISA layer boundaries, phase transitions). The Newton solver may show convergence issues there — in which case use Levenberg-Marquardt or homotopy.
