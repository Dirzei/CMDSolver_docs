Architektur der Built-in Funktionen

Jede thermodynamische Funktion func(args) in BIfunctions hat drei Signaturen die zusammen das Interface für den Solver bilden:

Signatur 1 — Residuum:
dFunc(output, inputs...) = output − func(inputs)
// Gibt 0 wenn output korrekt berechnet wurde
// Wird als Gleichungsresiduum F(x) = 0 verwendet
Signatur 2 — List-Form:
dFunc(List<Double> values)
// Wrapper für EqnData-Aufruf via Reflection
Signatur 3 — Partielle Ableitung:
funcDeriv(variables, values, partial)
// Numerische Ableitung ∂(dFunc)/∂x_partial
// Verwendet 5-Punkte-Formel, O(h⁴) Genauigkeit
Warum diese Struktur? Der Solver braucht für jede Gleichung zwei Dinge: das Residuum F(x) und die Ableitungen ∂F/∂xᵢ für die Jacobi-Matrix. Für Built-in Funktionen kann CASprzak nicht symbolisch differenzieren — daher numerische Ableitungen via funcDeriv.

Beispiel — cpOfTNOZ

// Residuum: cp - cpOfTNOZ(T, WGR, FAR) = 0
public static double dCpOfTNOZ(double cp, double temp, double wgr, double far) {
    return cp - cpOfTNOZ(temp, wgr, far);
}

// In der CAS-Datei:
CALL(NOZ.CP) = pCPOFTNOZ(NOZ.TT, NOZ.WGR, NOZ.FAR);

Ableitungsmethodik — 5-Punkte-Formel

Alle partiellen Ableitungen der Built-in Funktionen werden numerisch berechnet — nicht symbolisch wie bei normalen CAS-Gleichungen. Dies ist nötig weil die thermodynamischen Polynome zu komplex für automatische Differentiation sind.

5-Punkte-Formel (O(h⁴) Genauigkeit):
df/dx ≈ [f(x−2h) − 8·f(x−h) + 8·f(x+h) − f(x+2h)] / (12h)
Adaptive Schrittweite:
h = adaptiveH(x) = max(|x| · 1e-5, 1e-8)
// Relativ zur Variablengröße — vermeidet Auslöschung
// Bei x = 200000 Pa: h ≈ 2 Pa (sinnvolle Schrittweite)
// Bei x = 0.001: h ≈ 1e-8 (absolute Untergrenze)
Genauigkeit: Die 5-Punkte-Formel hat einen Fehler von O(h⁴) — bei h=1e-5·x ist der Ableitungsfehler typisch unter 1e-10 relativ. Das ist ausreichend für Newton-Konvergenz bis fsum ~ 1e-9.

Schallgeschwindigkeits-Funktionen

Die Schallgeschwindigkeit in Luft/Abgas hängt von Temperatur, Druck und Gaszusammensetzung ab. CMDSolver verwendet JANAF-Polynome für die thermodynamischen Eigenschaften als Basis.

Schallgeschwindigkeit (allgemein):
a = √(κ · R · T)
// κ = cp/cv = Isentropenexponent
// R = spezifische Gaskonstante [J/kgK]
// T = Temperatur [K]
JANAF-basierte Berechnung:
cp(T) = Σ aᵢ · Tⁱ (Polynom in T)
κ(T) = cp(T) / (cp(T) − R)
a(T, p, Zusammensetzung) = √(κ · R · T)
softdryJANAF(soft, temp, pt, fN2, fO2, fAr, fCO2, fNe, fHe, fCH4, fKr, fH2, fN2O, fXe)
Schallgeschwindigkeit trockener Luft basierend auf JANAF-Thermodynamik. Berücksichtigt die vollständige Gaszusammensetzung (N₂, O₂, Ar, CO₂, Ne, He, CH₄, Kr, H₂, N₂O, Xe).

Enthalpie- und cp-Funktionen

JANAF-Polynome

JANAF (Joint Army-Navy-Air Force) Thermochemische Tabellen liefern Polynomkoeffizienten für thermodynamische Eigenschaften von Gasen in Abhängigkeit von der Temperatur. CMDSolver verwendet diese für cp(T) und h(T).

JANAF cp-Polynom:
cp(T) = R · (a₁ + a₂·T + a₃·T² + a₄·T³ + a₅·T⁴)
JANAF Enthalpie:
h(T) = R · (a₁·T + a₂·T²/2 + a₃·T³/3 + a₄·T⁴/4 + a₅·T⁵/5 + a₆)
// a₆ = Integrationskonstante (Bildungsenthalpie)
Gemischung (mehrere Gaskomponenten):
cp_mix(T) = Σᵢ fᵢ · cpᵢ(T) (massengewichtetes Mittel)
cpofTJANAF(cpoft, temp, fN2, fO2, fAr, fCO2, fNe, fHe, fCH4, fKr, fH2, fN2O, fXe, fH2O)
Spezifische Wärmekapazität cp bei gegebener Temperatur und Gaszusammensetzung (einschließlich Wasser). JANAF-Polynome, gültig für T = 200K bis 6000K.

p_sat(T) = exp(A − B/(C + T)) [Antoine-Gleichung]
// Koeffizienten A, B, C aus NIST-Datenbank

Atmosphärenmodell — ISA

Das International Standard Atmosphere (ISA) Modell beschreibt Temperatur und Druck als Funktion der Höhe. CMDSolver implementiert das vollständige ISA-Modell bis 80km Höhe mit 9 Schichten.

ISA Temperaturprofil (schichtenweise):
T(h) = Tⱼ + βⱼ · (h − hⱼ) [K]
ISA Druckprofil:
In Gradientschichten (βⱼ ≠ 0):
p(h) = pⱼ · (T(h)/Tⱼ)^(−g/(R·βⱼ))
In Isothermschichten (βⱼ = 0):
p(h) = pⱼ · exp(−g·(h−hⱼ)/(R·Tⱼ))
ISA + ΔTISA (Temperaturabweichung vom Standard):
T_eff(h) = T_ISA(h) + ΔTISA

Strömungsmechanische Funktionen

MofCondiRatio(m, arat, kappa)
Machzahl aus dem Flächenverhältnis A/A* (Kanaldivergenz-Verhältnis). Löst die isentrope Durchflussgleichung numerisch.
Isentrope Durchflussgleichung:
A/A* = (1/Ma) · [(2/(κ+1)) · (1 + (κ−1)/2 · Ma²)]^((κ+1)/(2(κ−1)))
// Wird nach Ma aufgelöst (numerisch, da transzendent)
m
Ausgabe: Machzahl [−]
arat
Flächenverhältnis A/A* [−]
kappa
Isentropenexponent κ = cp/cv [−]
Bedeutung für Düsenmodelle: MofCondiRatio ist zentral für alle konvergent-divergenten Düsenberechnungen (Laval-Düse). Das Flächenverhältnis bestimmt eindeutig die Machzahl — bis auf die Zweideutigkeit subsonic/supersonic die durch die Randbedingungen aufgelöst wird.

Vollständiges Prozedurenbeispiel

// Prozedurendeklaration am Dateianfang
PROCEDURE pSOFTWETJANAF
CALL:    SOFTWETJANAF;
INPUTS:  REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL, REAL;
OUTPUTS: REAL;
END

// Verwendung in Gleichung
CALL(PARTM.F060.SOFT) = pSOFTWETJANAF(
    PARTM.F060.TT, PARTM.F060.PT,
    AMB.FN2, AMB.FO2, AMB.FAR, AMB.FCO2,
    AMB.FNE, AMB.FHE, AMB.FCH4, AMB.FKR,
    AMB.FH2, AMB.FN2O, AMB.FXE,
    AMB.FH2O, AMB.FH2O
);
Hinweis zur Ableitungsqualität: Da Built-in Funktionen numerisch differenziert werden, können an Unstetigkeitsstellen (z.B. ISA-Schichtgrenzen, Phasenübergänge) Ableitungsfehler auftreten. Der Newton-Solver kann dort Konvergenzprobleme zeigen — in diesem Fall Levenberg-Marquardt oder Homotopie verwenden.
