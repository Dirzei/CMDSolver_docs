SolverAPI

SolverAPI

SolverAPI cmd.SolverAPI
Programmatischer Einstiegspunkt für CMDSolver ohne CLI. Kapselt Laden, Konfiguration und Ausführung in einer fluenten API. Thread-safety: eine Instanz pro Thread.
Programmatic entry point for CMDSolver without CLI. Encapsulates loading, configuration, and execution in a fluent API. Thread safety: one instance per thread.
SolverAPI SolverAPI()
Erzeugt eine neue SolverAPI-Instanz mit Standard-Konfiguration (Newton-Armijo, tol=1e-7, maxIter=100).
Creates a new SolverAPI instance with default configuration (Newton-Armijo, tol=1e-7, maxIter=100).
SolverAPI loadModel(String filePath) throws IOException ↩ this
Lädt und parst eine CAS-Datei vom Dateisystem. Muss vor solve() aufgerufen werden.
Loads and parses a CAS file from the file system. Must be called before solve().
Gibt: diese Instanz für Method-Chaining
Returns: this instance for method chaining
new SolverAPI().loadModel("model.cas").solve();
SolverAPI loadModelFromString(String content, long refVal) ↩ this
Lädt das CAS-Modell aus einem String statt aus einer Datei. Nützlich für dynamisch generierte Modelle oder Unit-Tests. refVal typisch: content.length().
Loads the CAS model from a string instead of a file. Useful for dynamically generated models or unit tests. refVal is typically content.length().
api.loadModelFromString(casContent, casContent.length());
SolverAPI loadVariableUpdate(String filePath) throws IOException ↩ this
Lädt eine -U:-Datei mit Variablen-Overrides (Startwerte, Bounds, Status). Äquivalent zu -U: auf der CLI.
Loads a -U: file with variable overrides (starting values, bounds, status). Equivalent to -U: on the CLI.
SolverAPI setVariableValue(String name, double value) ↩ this
Setzt den Startwert einer freien Variablen. Der Status (Free/Fixed) wird nicht geändert. Name ist case-insensitiv.
Sets the starting value of a free variable. The status (Free/Fixed) is not changed. Name is case-insensitive.
api.setVariableValue("PARTM.F060.TT", 800.0);
SolverAPI setVariableFixed(String name, double value) ↩ this
Fixiert eine Variable auf den angegebenen Wert — ändert Status auf Fixed und setzt den Wert. Damit wird die Variable zur Randbedingung.
Fixes a variable to the given value — changes its status to Fixed and assigns the value. This turns the variable into a boundary condition.
api.setVariableFixed("AMB.PS", 98136.535); // Umgebungsdruck fixieren// Fix the ambient pressure
SolverAPI setSolverType(SolverType type) ↩ this
Wählt den Solver-Algorithmus. Standard: NEWTON_ARMIJO. Empfohlen: NEWTON_SPARSE_ARMIJO für die meisten Systeme.
Selects the solver algorithm. Default: NEWTON_ARMIJO. Recommended: NEWTON_SPARSE_ARMIJO for most systems.
api.setSolverType(SolverType.NEWTON_SPARSE_ARMIJO);
SolverAPI setTolerance(double tolerance) ↩ this
Setzt die absolute Konvergenzschwelle ||F(x)|| < tolerance. Standard: 1e-7.
Sets the absolute convergence threshold ||F(x)|| < tolerance. Default: 1e-7.
SolverAPI setToleranceRelative(double toleranceRelative) ↩ this
Relatives Abbruchkriterium (neu in v2.10). Konvergenz wenn fsum/fsum_initial < toleranceRelative. Verhindert Dominanz großer Gleichungen (Pa neben kg/s). Standard: 0 (deaktiviert).
Relative termination criterion (new in v2.10). Convergence when fsum/fsum_initial < toleranceRelative. Prevents dominance by large equations (Pa next to kg/s). Default: 0 (disabled).
api.setToleranceRelative(1e-4); // 10.000× Verbesserung als Kriterium
SolverAPI setMaxIterations(int maxIter) ↩ this
Maximale Iterationen vor Abbruch. Standard: 100. Bei LM oder Homotopie ggf. auf 200+ erhöhen.
Maximum iterations before abort. Default: 100. For LM or homotopy, raise to 200+ if needed.
SolverAPI setScaling(ScalingStrategy strategy) ↩ this
Setzt die Skalierungsstrategie. NONE (Standard), DIAGONAL, UNIT_INTERVAL. Aktuell nur NONE aktiv — andere sind vorbereitet.
Sets the scaling strategy. NONE (default), DIAGONAL, UNIT_INTERVAL. Currently only NONE is active — others are prepared.
SolverAPI setResidualNormalization(boolean enabled) ↩ this
Aktiviert Residuen-Normierung: fsum = Σ|Fᵢ(x)|/|Fᵢ(x₀)|. Hilfreich bei Systemen mit sehr unterschiedlichen Gleichungsgrößen.
Enables residual normalization: fsum = Σ|Fᵢ(x)|/|Fᵢ(x₀)|. Helpful for systems with widely varying equation magnitudes.
SolverAPI setDiagnoseMode(boolean enabled) ↩ this
Aktiviert Diagnose-Modus: InitialValueAnalyzer optimiert Startwerte vor dem Solve. Äquivalent zu -DI. Empfohlen bei schlechten Startwerten.
Enables diagnostic mode: InitialValueAnalyzer optimizes starting values before the solve. Equivalent to -DI. Recommended when starting values are poor.
SolverAPI setHomotopyConfig(HomotopyConfig config) ↩ this
Setzt Homotopie-Konfiguration — nur relevant wenn setSolverType(HOMOTOPY). Vorgefertigte Konfigurationen: HomotopyConfig.defaultConfig(), HomotopyConfig.criticalConfig().
Sets homotopy configuration — only relevant when setSolverType(HOMOTOPY). Predefined configurations: HomotopyConfig.defaultConfig(), HomotopyConfig.criticalConfig().
api.setSolverType(SolverType.HOMOTOPY) .setHomotopyConfig(HomotopyConfig.criticalConfig()); // für κ > 10¹²
SolverAPI setSolverConfig(SolverConfig config) ↩ this
Setzt eine vollständige SolverConfig — überschreibt alle vorherigen setSolverType/setTolerance/etc. Aufrufe. Für maximale Kontrolle.
Sets a complete SolverConfig — overrides any prior setSolverType/setTolerance/etc. calls. For maximum control.
SolverResult solve()
Führt den Solve-Prozess aus. Gibt immer ein SolverResult zurück — auch bei Fehler oder Nicht-Konvergenz. Nie null. Gibt nie eine Exception wenn loadModel() vorher erfolgreich war.
Runs the solve. Always returns a SolverResult — even on failure or non-convergence. Never null. Never throws if loadModel() succeeded earlier.
Gibt: SolverResult mit vollständigem Lösungsvektor oder Fehlerstatus

SolverResult

SolverResult

SolverResult cmd.SolverResult — final, nicht instanziierbar
Unveränderliches Ergebnisobjekt von SolverAPI.solve(). Enthält Konvergenzstatus, Lösungsvektor, ParseErrors und Ausgabemethoden.
Immutable result object from SolverAPI.solve(). Contains convergence status, solution vector, ParseErrors, and output methods.
boolean isConverged()
Gibt true zurück wenn ||F(x)|| < tolerance.
Returns true if ||F(x)|| < tolerance.
int getIterations()
Anzahl Solver-Iterationen. -1 wenn nicht verfügbar (Homotopie).
Number of solver iterations. -1 if unavailable (Homotopy).
double getFinalResidual()
Finales ||F(x)|| nach letztem Iterationsschritt. NaN wenn nicht verfügbar.
Final ||F(x)|| after the last iteration step. NaN if unavailable.
String getErrorMessage()
Fehlermeldung wenn nicht konvergiert. null bei Erfolg.
Error message when not converged. null on success.
double getValue(String variableName)
Gelöster Wert einer Variablen. Name ist case-insensitiv. Gibt Double.NaN wenn Variable nicht vorhanden oder kein Ergebnis.
Solved value of a variable. Name is case-insensitive. Returns Double.NaN if the variable is missing or no result is available.
double pt = result.getValue("PARTM.F060.PT"); if (Double.isNaN(pt)) { /* Variable nicht gefunden */ }
boolean hasValue(String variableName)
Prüft ob eine Variable im Lösungsvektor vorhanden ist.
Checks whether a variable is present in the solution vector.
Map<String, Double> getAllValues()
Alle gelösten Variablenwerte als unveränderliche Map. Schlüssel sind Großbuchstaben-Variablennamen. Leere Map wenn kein Ergebnis.
All solved variable values as an immutable map. Keys are uppercase variable names. Empty map if no result.
boolean hasParseErrors()
Gibt true wenn fatale ParseErrors beim CAS-Parsing aufgetreten sind.
Returns true if fatal ParseErrors occurred during CAS parsing.
List<ParseError> getParseErrors()
Alle ParseErrors (ERROR/WARNING/INFO) aus dem Parser-Lauf. Leere Liste wenn keine.
All ParseErrors (ERROR/WARNING/INFO) from the parser run. Empty list if none.
String formatAsString()
Vollständiger Lösungsvektor als formatierter String — alle Variablen mit Wert, Bounds, Einheit und Status.
Complete solution vector as a formatted string — all variables with value, bounds, unit, and status.
void writeToFile(String filePath) throws IOException
Schreibt den Lösungsvektor in eine Datei (Semikolon-getrenntes Format).
Writes the solution vector to a file (semicolon-separated format).
void writeToWriter(Writer writer) throws IOException
Schreibt den Lösungsvektor in einen beliebigen Writer — für GUI-Integration via StringWriter oder direkt in JTextArea.
Writes the solution vector to any Writer — for GUI integration via StringWriter or directly into JTextArea.
StringWriter sw = new StringWriter(); result.writeToWriter(sw); textArea.setText(sw.toString());

SolverConfig.Builder

SolverConfig.Builder

SolverConfig.Builder apps.eqnParser.solver.SolverConfig.Builder
Builder-Pattern für vollständige Solver-Konfiguration. Für einfache Fälle genügt SolverAPI.setSolverType() / setTolerance(). Builder bietet Zugang zu allen internen Parametern.
Builder pattern for complete solver configuration. For simple cases, SolverAPI.setSolverType() / setTolerance() is sufficient. The builder provides access to all internal parameters.
Builder solverType(SolverType v)
Solver-Algorithmus. Standard: NEWTON_ARMIJO.
Solver algorithm. Default: NEWTON_ARMIJO.
Builder maxIter(int v)
Maximale Iterationen. Standard: 100.
Maximum iterations. Default: 100.
Builder tolerance(double v)
Konvergenzschwelle. Standard: 1e-7.
Convergence threshold. Default: 1e-7.
Builder armijoAlphaInit(double v)
Initialer Schrittweiten-Faktor für Armijo-Backtracking. Standard: 1.0.
Initial step-size factor for Armijo backtracking. Default: 1.0.
Builder armijoAlphaMin(double v)
Minimales α vor Abbruch der Liniensuche. Standard: 1e-4.
Minimum α before line search aborts. Default: 1e-4.
Builder armijoRho(double v)
Reduktionsfaktor pro Backtracking-Schritt. Standard: 0.5.
Reduction factor per backtracking step. Default: 0.5.
Builder lmMuInit(double v)
Initialer LM-Dämpfungsparameter. Standard: 1e-6.
Initial LM damping parameter. Default: 1e-6.
Builder lmNuUp(double v) / lmNuDown(double v)
μ-Erhöhungsfaktor (Standard: 2.0) und Reduktionsfaktor (Standard: 5.0) für LM.
μ increase factor (default: 2.0) and reduction factor (default: 5.0) for LM.
Builder broydenResetInterval(int v)
Jacobi-Reset-Intervall für Broyden. Standard: 25.
Jacobian reset interval for Broyden. Default: 25.
Builder residualNormalization(boolean v)
N3-Residuen-Normierung aktivieren. Standard: false.
Enable N3 residual normalization. Default: false.
SolverConfig build()
Erzeugt eine unveränderliche SolverConfig-Instanz.
Creates an immutable SolverConfig instance.
SolverConfig cfg = new SolverConfig.Builder() .solverType(SolverType.LEVENBERG_MARQUARDT) .maxIter(200) .lmMuInit(1e-4) .build(); api.setSolverConfig(cfg);

ParseError

ParseError apps.eqnParser.ParseError
Typisierter Parser-Fehler mit Severity, Zeilennummer und Kontext. Erzeugt von EqnSysReader, abgerufen via SolverResult.getParseErrors().
Typed parser error with severity, line number, and context. Produced by EqnSysReader, retrieved via SolverResult.getParseErrors().
Severity getSeverity()
Schweregrad: ERROR (fatal, Solve nicht möglich), WARNING (möglicherweise problematisch), INFO (informativ).
int getLineNumber()
Zeilennummer in der CAS-Datei wo der Fehler aufgetreten ist. -1 wenn nicht bekannt.
Line number in the CAS file where the error occurred. -1 if unknown.
String getMessage()
Fehlerbeschreibung.
Error description.
String getContext()
Zeilen-Inhalt oder Kontext-String zur Fehlerlokalisierung. Kann null sein.
Line content or context string for error localization. May be null.
String format()
Formatierter String: [ERROR] Line 47: Beschreibung — Kontext
Formatted string: [ERROR] Line 47: description — context
for (ParseError e : result.getParseErrors()) { System.err.println(e.format()); }

SolverType — Enum

SolverType apps.eqnParser.solver.SolverType
Aufzählung aller verfügbaren Solver-Algorithmen.
Enumeration of all available solver algorithms.
NEWTON_ARMIJO // Newton-Raphson + Armijo Liniensuche (dichte LU) NEWTON_SPARSE // Newton-Raphson + GSPAR Sparse-LU (kein Backtracking) NEWTON_SPARSE_ARMIJO // Newton + GSPAR Sparse-LU + Armijo ★ Empfohlen LEVENBERG_MARQUARDT // LM — robust bei κ > 10¹² BROYDEN // Broyden Quasi-Newton (Rang-1 Update, dichte LU) BROYDEN_SPARSE // Broyden + GSPAR — schnellster in Tests HOMOTOPY // Arc-Length Continuation — global, langsam
String getDescription()
Beschreibungstext des Solvers für Log-Ausgaben.
Descriptive text of the solver for log output.
static SolverType fromString(String name)
Parst einen SolverType aus einem String. Case-insensitiv. Gibt NEWTON_ARMIJO als Fallback wenn unbekannt.
Parses a SolverType from a string. Case-insensitive. Returns NEWTON_ARMIJO as fallback if unknown.

HomotopyConfig

HomotopyConfig apps.eqnParser.solver.HomotopyConfig
Konfiguration für den Homotopie-Solver. Vorgefertigte Konfigurationen decken die häufigsten Anwendungsfälle ab.
Configuration for the homotopy solver. Predefined configurations cover the most common use cases.
static HomotopyConfig defaultConfig()
Standard: 10 Schritte, ds=0.1, innerer Solver: NEWTON_ARMIJO.
Default: 10 steps, ds=0.1, inner solver: NEWTON_ARMIJO.
static HomotopyConfig criticalConfig()
Für schwierige Systeme (κ > 10¹², Ma-Übergänge): 50 Schritte, ds=0.02, dsMax=0.1, iterTarget=3.
For challenging systems (κ > 10¹², Ma transitions): 50 steps, ds=0.02, dsMax=0.1, iterTarget=3.
// Für NozzleSystem oder stark nichtlineare Modelle: api.setSolverType(SolverType.HOMOTOPY) .setHomotopyConfig(HomotopyConfig.criticalConfig()) .solve();
