Grundidee — allgemein verständlich

Core idea — in plain terms

Levenberg-Marquardt (LM) löst das Problem dass Newton-Raphson bei schlecht konditionierten Systemen versagt. Die Idee: Man fügt der Jacobi einen Dämpfungsterm μ·I hinzu. Das macht das System numerisch stabiler — ähnlich wie man eine wackelige Leiter durch einen Stützpunkt sichert.

Levenberg-Marquardt (LM) tackles the problem that Newton-Raphson fails on ill-conditioned systems. The idea: add a damping term μ·I to the Jacobian. This makes the system numerically more stable — like bracing a wobbly ladder with an extra support.

Der Parameter μ wird adaptiv angepasst: Wenn der Schritt gut war (Residuum sinkt), wird μ verkleinert (→ Newton-artig, schneller). Wenn der Schritt schlecht war, wird μ vergrößert (→ Gradientenabstieg, stabiler).

The parameter μ is adapted dynamically: when a step is good (residual drops) μ is reduced (→ more Newton-like, faster). When a step is bad, μ is increased (→ gradient descent, more stable).

LM-System:LM system: (JᵀJ + μ·I) · Δx = −Jᵀ·F(x)
μ-Anpassung:μ adaptation:
Schritt gut (||F(x+Δx)|| < ||F(x)||) → μ ← μ / νdown ← schneller
Good step (||F(x+Δx)|| < ||F(x)||) → μ ← μ / νdown ← faster
Schritt schlecht → μ ← μ · νup ← stabiler
Bad step → μ ← μ · νup ← more stable
Grenzfälle:Limit cases:
μ → 0 : reines Newton-Raphson (quadratisch, schnell)
μ → 0 : pure Newton-Raphson (quadratic, fast)
μ → ∞ : skalierter Gradientenabstieg (robust, langsam)
μ → ∞ : scaled gradient descent (robust, slow)

Warum JᵀJ + μI statt nur J?

Why JᵀJ + μI instead of just J?

Bei fast-singulärer Jacobi J sind kleine Singulärwerte nahe 0 — das erzeugt riesige Lösungskomponenten in Δx. JᵀJ + μI ist immer positiv definit (alle Eigenwerte ≥ μ > 0) — das garantiert algebraische Stabilität. Numerisch ist die Wirkung allerdings begrenzt, weil JᵀJ die Konditionszahl quadriert: κ(JᵀJ) ≈ κ(J)². Bei κ(J) > 10⁸ übersteigt das Maschinengenauigkeit. Der Preis ist also doppelt: mehr Iterationen als Newton, plus engerer Konditionsbereich als die bloße Algebra suggeriert.

For a near-singular Jacobian J, small singular values near 0 produce huge components in Δx. JᵀJ + μI is always positive definite (all eigenvalues ≥ μ > 0) — guaranteeing algebraic stability. Numerically the effect is limited though, because JᵀJ squares the condition number: κ(JᵀJ) ≈ κ(J)². At κ(J) > 10⁸ this exceeds machine precision. The price is therefore double: more iterations than Newton, and a tighter conditioning regime than the bare algebra suggests.

LM in CMDSolver — Implementierungsdetails

LM in CMDSolver — implementation details

In CMDSolver verwendet LM die dichte MatrixSimple für die (JᵀJ + μI)-Zerlegung. μ wird beim ersten Schritt aus der Jacobi-Diagonale initialisiert (μ = lmMuInit · maxDiag) und danach adaptiv angepasst. Bei singulärer Matrix wird μ erhöht und der Schritt wiederholt.

In CMDSolver, LM uses the dense MatrixSimple for the (JᵀJ + μI) factorization. μ is initialized from the Jacobian diagonal at the first step (μ = lmMuInit · maxDiag) and adapted from then on. If the matrix is singular, μ is increased and the step is retried.

function levenberg_marquardt_solve(F, x₀, tol, maxIter):
    x ← InitGuessApplier(x₀)
    μ ← 0  // wird beim ersten Schritt initialisiert// initialized at first step

    for k = 0 to maxIter:
        J ← buildJacobian(F, x)
        f ← F(x)
        JtJ ← Jᵀ · J

        // μ initialisieren (Iteration 0)// initialize μ (iteration 0)
        if k == 0:
            μ ← lmMuInit · max(diag(JtJ))

        // ── LM-System lösen (mit Wiederholung bei singulärer Matrix) ──// ── Solve LM system (with retry on singular matrix) ──
        for attempt = 1 to maxAttempts:
            A ← JtJ + μ·I             // regularisiert, immer pd// regularized, always pd
            try:
                Δx ← solve(A, −Jᵀ·f)
                break
            except Singular:
                μ ← μ · νup           // erhöhen und wiederholen// increase and retry

        // ── Schritt testen ──// ── Test step ──
        x_try ← x + Δx
        if ||F(x_try)|| < ||f||:
            x ← x_try
            μ ← μ / νdown            // Newton-artiger// more Newton-like
        else:
            μ ← μ · νup              // stabiler// more stable

        x ← PhysicalProjector(x)
        fsum ← Σ|Fᵢ(x)|
        if fsum < tol: return CONVERGED, x, k, fsum

    return NOT_CONVERGED, x, maxIter, fsum

Bekannte Grenzen — und der v2.12-Fix

Known Limitations — and the v2.12 Fix

v2.12 Update (Newton-Direkt-Hybrid): Die alte Grenze "LM nicht zuverlässig bei kappa > 10⁸" wurde durch eine architektonische Verbesserung weitgehend aufgehoben. Bei kleinem μ (wo LM mathematisch ≈ Newton ist) lösen wir jetzt direkt dx = -J⁻¹·f wie Newton, statt über die Normalengleichung — das vermeidet die kappa²-Verlust. NozzleSystem (kappa = 4.6×10¹¹) konvergiert mit -S:LEVENBERG_MARQUARDT -SC:EQUILIBRATE jetzt in 5 Iter, identisch zu Newton-Armijo.
v2.12 update (Newton-direct hybrid): the old limit "LM unreliable at kappa > 10⁸" has been largely lifted by an architectural improvement. At small μ (where LM is mathematically ≈ Newton) we now solve dx = -J⁻¹·f directly like Newton instead of via the normal equation — avoiding the kappa² loss. NozzleSystem (kappa = 4.6×10¹¹) now converges with -S:LEVENBERG_MARQUARDT -SC:EQUILIBRATE in 5 iterations, identical to Newton-Armijo.
Mehr Iterationen ohne Equilibrator: LM konvergiert superlinear statt quadratisch — bei aktiver μ-Regularisierung typisch 10-30 Iterationen statt 3-5. Bei gut konditionierten Systemen ist Newton-Sparse-Armijo schneller. Mit Equilibrator und Newton-Direkt-Hybrid erreicht LM jedoch Newton-Niveau.
More iterations without equilibrator: LM converges superlinearly, not quadratically — with active μ regularization typically 10–30 iterations instead of 3–5. On well-conditioned systems Newton-Sparse-Armijo is faster. With the equilibrator and the Newton-direct hybrid, LM reaches Newton-level performance.
Dichte JᵀJ wird nur als Fallback benutzt: Im Newton-Direkt-Pfad wird JᵀJ gar nicht erst gebildet — nur bei größerem μ (rückgewiesene Schritte) greift die klassische Marquardt-Form mit (JᵀJ + μ·D). Schwellenwerte: μ < 10⁻⁴ bei aktivem Equilibrator (Levenberg-Form), μ < 10⁻⁶ sonst.
Dense JᵀJ is only used as a fallback: in the Newton-direct path, JᵀJ is not formed at all — only at larger μ (rejected steps) does the classical Marquardt form with (JᵀJ + μ·D) kick in. Thresholds: μ < 10⁻⁴ with an active equilibrator (Levenberg form), μ < 10⁻⁶ otherwise.
Modell-Singularitäten an Bounds: Wenn das Modell selbst Singularitäten an Variablen-Bounds hat (z.B. 1/(γ-1) mit γ.Lower = 1.0), schießt der erste Newton-Schritt die Variable an die Bound, und die nachfolgende Funktionsauswertung wird NaN. Das ist kein Solver-Bug, sondern ein Modell-Issue. Lösung: realistische Bounds setzen (z.B. γ.Lower = 1.05) oder Equilibrator nutzen damit die Konvergenz schnell genug ist.
Model singularities at bounds: if the model itself has singularities at variable bounds (e.g. 1/(γ-1) with γ.Lower = 1.0), the first Newton step pushes the variable onto the bound and the subsequent function evaluation becomes NaN. This is not a solver bug but a model issue. Fix: set realistic bounds (e.g. γ.Lower = 1.05) or use the equilibrator so convergence is fast enough to avoid the bound.
